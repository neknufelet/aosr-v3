第②層：`from typing import *`——看不見綁定就不准。

星號 import 把一整包名字倒進這個檔。之後寫 `def f(x: Any)`，那個 Any 是從哪裡來的、
有沒有被綁成別的名字，靜態上看不出來——第②層在這個檔就量不到東西了。

這是「改名 import 的 Any」那個洞的第三條路，而且它比另外兩條更難處理：另外兩條
解析得出綁定，這一條解析不出來。所以判準是「這一行本身就是違規」，不是「等它真的
用到 Any 才咬」——量不到就不准當乾淨，跟這個 repo 每一張卡在做的事同一個判準。

只咬 typing 那一族的星號 import（`from typing import *`、`from typing_extensions
import *`）。`from os import *` 不歸這張卡管，那是別的問題。

裡面那支 passthrough() 本身完全合規（標得好好的，型別也對），所以這棵樹回 1 的
唯一理由就是檔頭那一行。第①層在這一份是乾淨的（實測餵給 mypy 回 0）。
