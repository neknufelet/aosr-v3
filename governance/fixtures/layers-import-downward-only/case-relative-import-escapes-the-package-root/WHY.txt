只犯一件事：用 `from ...xxx` 那種往上數幾層的寫法。

`config` 底下的一支檔寫 `from ...physics import solver`：兩個點已經數到新引擎的最外層，
第三個點數到新引擎外面去了，而程式跑起來又會繞回這棵樹裡的 physics
——跟直接寫「去拿 aosr.physics 的 solver」是同一條往上拿的線，只是點的數目看不出來。

這一份是 2026-09-11 別家模型來找碴時戳出來的：第一版的程式把這種寫法
跟「去拿新引擎外面的別人家套件」當成同一件事、兩種都丟掉不看，
於是同一條線改成三個點就回綠了。現在判紅，訊息裡直接說「這是往上數幾層的寫法」。

除了那一行以外這棵樹是乾淨的：physics 什麼都不拿，不會順便繞成圈。
