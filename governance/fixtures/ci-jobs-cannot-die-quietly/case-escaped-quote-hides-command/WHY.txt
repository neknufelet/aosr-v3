第⑤條：收據那個 job（verify）底下有一步是 `抄寫員 … \" && uv run pytest #"`。
bash 讀到 `\"` 是一個被跳脫的雙引號字元，不開引號，所以 `&& uv run pytest` 在引號外、前一段成功就會執行、沒包抄寫員；
行尾的 `#"` 是註解。

舊版把 `\"` 當成引號開頭、一路配到行尾那個 `"`，`&& uv run pytest` 被當成引號裡的字、不切，整行放行。
現在引號外反斜線跳脫的那一個字元是字面，不開引號、也不是分隔符。

這一份裡只留兩步：`uv sync --locked` 是水管，另一步就是這一行，紅的只會是它。
