第⑤條：收據那個 job（verify）底下有一步是 `抄寫員 … --a=b#c && uv run pytest`。
bash 只在**字首**認 `#` 是註解，`b#c` 的 `#` 是字的一部分，所以 `&& uv run pytest` 照跑，而且沒包抄寫員。

舊版把引號外第一個 `#` 之後全當註解剝掉，連 `&& uv run pytest` 一起剝了，整行只剩抄寫員那一段、放行。
現在 `#` 前面是空白、Tab、換行、`;&|()<>` 或在行首才是註解起點。

這一份裡只留兩步：`uv sync --locked` 是水管，另一步就是這一行，紅的只會是它。
