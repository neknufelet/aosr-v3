第⑤條：收據那個 job（verify）底下有一步是 `抄寫員 … $'\'' && uv run pytest #'`。
bash 的 `$'…'`（ANSI-C 引號）裡反斜線會跳脫單引號，`$'\''` 就是一個單引號字元、在第二個 `'` 收尾，
所以 `&& uv run pytest` 在引號外、前一段成功就會執行、沒包抄寫員；行尾的 `#'` 是註解。

舊版把 `'\'` 當成一對普通單引號，再把下一個 `'` 一路配到行尾，`&& uv run pytest` 被藏進引號裡，整行放行。
現在奇數個 `$` 緊接的單引號照 `$'…'` 讀（偶數個 `$$` 是行程號，後面是普通引號）。

這一份裡只留兩步：`uv sync --locked` 是水管，另一步就是這一行，紅的只會是它。
