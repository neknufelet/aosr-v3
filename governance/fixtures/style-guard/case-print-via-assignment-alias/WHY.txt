第①條：用賦值把 print 換個名字（`p = print`，之後 `p(...)`）。

這一份不是想出來的，是 issue #47 上實測戳出來的洞。立卡當天第①條只比呼叫對象攤平後的
字面（`print` 這個字），所以：

  p = print
  p("開始掃了")

第①條 hits=0——改個名字就整條繞過去。這一份就是那個洞的迴歸。

修法：先解析這份檔的名字綁定（共用零件 governance/names.py），再問「這個呼叫對象回指
哪一個 (模組, 名字)」。`p = print` 之後 `p` 回指的還是 builtins.print，所以照樣咬。

這一份是完整的迷你掃描根：一支違規的 .py、一張只帶 id 與 [settings] 的迷你卡，加這份 WHY.txt。
