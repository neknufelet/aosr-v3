    階段


    可擺範圍

    這份方案沒有設喇叭類型與擺法，喇叭高度與箱體要在這裡填（也可以回方案輸入頁設好）。

    房間尺寸範圍（第一階段；空白的邊照方案的房間）

    房間尺寸一起搜時，不能同時鎖座位、設禁區或喇叭可用區（那幾樣用房間的絕對座標）。

    硬限制（空白＝不限制）

    禁區（門、走道：箱體與座位都不准進；房間座標，公尺）

    喇叭可用區（聲學中心只准在這些盒子裡；一塊都沒有＝不限制）

    預算與停止

    題數上限與「連續幾個沒改善就停」是暫行的工程停止設定，沒有產品預設（要實跑後問老闆），一定要填； 不確定就從之前的一場帶入。用完預算停下來不代表找到最好的。
