# 音色在實際計分的頻率範圍裡缺一段就是不可估

## 問題

音色評估器抓得到頻率軸中間的洞，但只掛一個「覆蓋不足」的旗標就繼續量，排名層也沒有任何規則讀那個旗標。把有深谷的那一段頻率整段拿掉，剩下的資料平直，量出來零傾斜、零起伏、沒有峰谷，零代價進榜——少交資料反而拿到好成績（2026-09-21 外部審查第 3 條，票 #394）。

同一個旗標還混著另一件無害的事：報表的頻率上限約 5.6 kHz，達不到登記簿的診斷覆蓋範圍上緣 8 kHz（票 #347），這一段不在任何計分範圍裡。

## 選項

1. **計分範圍內缺段就不可估。** 傾斜擬合範圍與起伏範圍（峰谷保護也在起伏範圍裡找）這兩個實際計分的範圍，裡面有缺段、或資料兩端接不到範圍邊界，音色這一類回不可估；只有診斷覆蓋範圍不足時照舊只掛旗標。
2. **照量，但把覆蓋情形算進比較身分。** 缺段的候選跟完整的分到不同表。
3. **照量，缺段那一段補一個懲罰值。**

## 決定

採 1。

- 「缺段」沿用評估器現有的判準：相鄰兩點的距離（八度）大於兩個平滑寬度裡較窄的那一個。不另立新數字。
- 判的範圍是傾斜擬合範圍與起伏範圍各自一次；範圍的上下邊界各當成一個虛擬的點——資料第一點離下邊界、最後一點離上邊界超過同一個距離，也是缺段。
- 缺段時回不可估，原因代碼指名「計分範圍內缺段」，跟「點數不夠」分開。音色是必評類，所以那個候選會列成「未評估」，不進榜；量得到的部分不回半套。
- 資料蓋不滿診斷覆蓋範圍、但兩個計分範圍都完整時，照舊只掛「覆蓋不足」旗標、照常量。

## 為什麼

缺段會讓三個計分量同時失真，而且方向一律對候選有利：坑不見了，擬合與起伏都變好。補懲罰值要發明一個沒有出處的數字；分表則會讓「交爛資料」變成一張自己的表，在那張表裡它還是第一名。不可估最誠實：這一份資料不足以回答這一題。

## 代價

- 物理報表若某一段頻率算不出來（例如之後某一路求解失敗只回部分頻點），整個候選會因為音色不可估而不進榜，不會降級成「先比其他類」。
- 判準綁著平滑寬度：之後拍平滑寬度（#339 清單第 3 題）時，缺段的門檻會跟著動，那一題要一併看這個後果。
- 現有一題考卷明文要求「有洞仍然算已量」，這一張之後它守的事反過來，要改寫。
