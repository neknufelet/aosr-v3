# 幾何、總能量、逐路徑振幅與低頻有限元素的精度契約

## 問題

2026-09-12 到 2026-09-13，老闆分四次拍了同一族的精度契約：鏡像幾何、逐路徑振幅、鏡像總壓力與能量、低頻有限元素。它們共同回答「v3 跟參考答案或獨立真值要對到多近、哪一支考卷守」，但原本散成四張紙。2026-09-21 決策紙份數滿了（票 #412），所以把四張目前仍有效的尺、公式、案例、設定名與守法責任合在這裡；舊紙原文留在封存區。

## 選項

- 幾何量當時在「`float.hex()` 的十六進位字串逐字相等」與「容許最後幾位差，例如 4 ULP（浮點數最小刻度）」之間選。
- 逐路徑振幅當時在「容差跟相位角成長」與「反射乘積採 2^-21、壓力全頻率一刀切 2e-4」之間選。
- 直達能量當時在 `2^-20` 的推導上界與 `2^-21` 的統計尺之間選；這一題只改先前 `2^-23` 的直達能量上限，沒有改總壓力與反射能量公式。
- 低頻有限元素當時在「上一代相容契約加解析解物理健檢」與「只保留上一代相容契約」之間選。

逐張的完整選項在封存區的舊紙；四張各有不同真值與誤差形狀，沒有一把共同的單一容差。

## 決定

**幾何量逐位元相同（2026-09-12）**

票 #175 產生第一段參考答案後，採逐位元相同方案。範圍是鏡像座標、路徑距離與到達時間：v3 每個浮點數的 `float.hex()`（十六進位浮點字串）必須跟答案檔逐字相等，不設容差。

- 裁判是 `tests/test_reference_room_answers.py` 的十六進位字串逐位比對，答案檔是 `blueprint/reference_room_answers.json`；第二段 v3 的三個幾何量走同一支裁判，不另寫一套。
- 換機器、函式庫或寫法若產生不同位元，要另立決策並附原因與證據，不准在考卷裡加容差。
- 這一小節只管幾何量；振幅、材料反應、二階以上反射與外部模擬器交叉驗證各自用自己的契約。逐路徑振幅的距離與到達時間仍由這顆逐位元的牙守。

**逐路徑振幅按相位角縮放（2026-09-12）**

第四段（票 #188）量到上一代以 `complex64`（單精度複數）計算振幅，角頻率 ω 與到達時間 τ 各切成一次 `float32`（單精度浮點數）；三階 63 條路徑、六個頻帶、兩組材料無法逐位元相同。因此採相位角縮放方案，範圍是每條路徑的反射乘積與壓力：

- 反射乘積每個分量的絕對差不得超過 `2^-21`，也就是單精度四格。
- 每條路徑壓力的相對差不得超過 `2^-21·(ωτ+1) + 2^-21/|反射乘積|`；相對差以複數差的模除以參考值的模計，且 `ω=2πf`、`τ=到達時間`。
- 直達路徑的反射乘積必須恰等於 1，不設容差；距離與到達時間由上一小節的逐位元裁判守。
- 不准日後直接放寬；超出就另立決策。總壓力與能量不拿逐路徑公式直接相加，而由下一小節的總量公式守。

**總壓力、反射能量與直達能量（2026-09-13）**

第十段（票 #219）把答案擴到三個接收點時，先前直達能量的 `2^-23` 相對差上限被超出：R1 在 2000 Hz 用到 107%，R2 在 250 Hz 用到 225%；逐路徑、總壓力與反射能量仍在界內。2026-09-13 這張紙因此只把直達能量從 `2^-23` 改為現在有效的 `2^-20`，其餘公式不變：

- 總壓力：`|Σ_k p_k − P2| ≤ sqrt(Σ_k (tol_k·|p_k|)²)`。
- 反射能量：`|R3 − R2| ≤ (2·sqrt(Σ_{k>0}(tol_k·|p_k|)²) / |Σ_{k>0} p_k| + 2^-23)·R2`。
- 直達能量：`|D3 − D2| ≤ 2^-20·D2`。
- 界線用 v3 自己算出的每條路徑值；總量定義照上一代。不准日後直接放寬；超出就另立決策。

`blueprint/precision_contracts.toml` 的 `direct_energy_vs_legacy`（直達能量對上一代）、`reflected_energy_floor`（反射能量地板）與 `reflection_product_ulp`（反射乘積浮點格數）三條登記會指向本紙；門檻的值仍只住該登記簿，產品程式不另開第二份。

**低頻有限元素採兩層契約（2026-09-13）**

第六段（票 #213）量完凍結的上一代：P1（一次元素）四面體、每波長六格、27×18×14 網格、250 Hz 上限、單精度稠密解；正式軸 29 點、1 Hz 細軸 241 點、精度地板 58 點。採兩層方案：

- 第一層相容契約：v3 對上一代 `flat`（平坦阻抗）案例，六面都是 `4·ρc`，每個頻點複數壓力須滿足 `|p3 − p2| ≤ 2^-12·|p2|`。網格維持 27×18×14、P1（一次元素）四面體、每波長六格，頻率軸照上一代正式軸：1/6 八度、10 Hz 起、≤250 Hz 共 29 點。
- 第二層物理健檢：剛性牆 `γ=0`，20 Hz 以下九個離共振點，按上一代的選點法在每個子頻帶取離所有本徵頻最遠的點；v3 對解析模態級數的相對差不得超過 `2^-10`。
- 參考答案入庫 `flat`（平坦阻抗）29 點與 `rigid`（剛性牆）正式軸 29 點加離共振 29 點；細軸與精度地板留在當時的外部證據。
- 採哪個數值函式庫是第七段開工前另一張決定；兩層都擋合併，不准日後直接放寬。

## 為什麼

- 幾何契約的證據是用標準函式庫獨立寫平方和開根號，七條路徑跟上一代逐位元相同；改用 `hypot`（直角邊合成函式）會差 1 ULP（浮點數最小刻度）。既然同位元做得到，二選一裁判比會逐漸長大的容差乾淨。
- 逐路徑振幅的實測相對差約為 `7e-8 × ωτ`，來自 ω、τ 各切一次單精度，再加三階反射乘積連乘誤差。公式讓 125 Hz 直達界線約為 `4e-6`，也會隨更大房間或更高頻率自動成長。63×6×2 格實測最壞用到壓力界線 22%、反射乘積界線 16%；一刀切 `2e-4` 在低頻會比真實差鬆 400 倍。
- 直達能量的誤差包括上一代以單精度計算 `|exp(−iωτ)|²` 時最大 `2×2^-23` 的偏差、距離切成單精度的 `2^-24` 並在平方後加倍、取倒數的 `2^-24` 並在平方後加倍，以及相乘的 `2^-24` 捨入，合計約 `4.5×2^-23`；先前 `2^-23` 只算了 `1／距離平方` 一次捨入。
- 同一條鏈隨機掃一百萬組，距離 0.5–10 m、頻率 20–8000 Hz，最大為 `4.63×2^-23`；`2^-20` 的尺在掃描最大值用到 58%，R2 實測用 28%，原接收點用 0.7%。超過 `2^-22` 的占 6.9%，超過 `2^-21` 的只有百萬分之六，所以可推導的直達誤差採嚴格上界，不採統計尺。
- 有限元素第一層的精度地板量過 58 點：上一代單精度對同鏈雙精度的相對差中位數 `6.3e-6`，最大 `1.4e-4`，發生在 12.6 Hz；`2^-12` 約 `2.4e-4`，最差用到 59%。
- 剛性牆對解析解只在 20 Hz 以下有意義：九點最大 `7.5e-4`，`2^-10` 用到 77%。再往上，P1（一次元素）網格把共振移動約 1%，正式軸多數點離最近本徵頻不到 1%，誤差由幾成到兩百倍；雙精度仍一樣，網格加密後離共振點按 `O(h²)`（網格尺度平方階）收斂。這九點是唯一不依賴任何產品程式的真值。

## 代價

- 幾何 v3 被綁在同一種算法寫法；改用 `hypot`（直角邊合成函式）或不同加法次序會紅。換平台若出現不同位元，必須走新決策。
- 逐路徑振幅界線是一條公式，考卷必須帶 ω、τ；`2^-21` 四格是留餘裕的選擇，不是嚴格推導值。
- 直達能量的尺相對先前放寬八倍，原接收點只用到 0.7%；考卷裡防止偷鬆尺的下限要同步。反射能量公式裡的 `+2^-23` 沒有重推，因每條路徑的 `tol_k`（路徑容差）已含 `2^-21`；日後若超出仍要另立決策。第五段已合入的常數需改一次，第十段入庫等這一改。
- 有限元素第一層只證明 v3 跟上一代相容，不證明這個網格夠準；第二層只蓋 20 Hz 以下，共振附近沒有契約，只有 1 Hz 細軸證據。上一代正式軸太粗、看不到模態；把軸做成設定另有票 #218。
- 合併帶來的代價：四種精度契約在機器眼裡變成同一題；以後任何一種尺或真值角色要翻案，都必須取代整張，並重述另外三種仍有效的契約。
