# 第五段做鏡像法的總壓力與能量，有限元素排第六段、分格材料等有人要

## 問題

第四段（票 #194）做完：v3 對參考房算到三階 63 條鏡像反射、每條帶材料吸收的振幅，跟上一代在契約內。
決策紙 `precision-contract-amplitude-phase-scaled` 明說「總壓力與能量的比法另訂」；第五段要拍做哪一個。

## 選項

1. **鏡像法的總壓力與能量**：把 63 條加起來（含相位）得接收點每個頻帶的總壓力，加上直達能量與反射能量，跟上一代比。
   要先拿證據訂總量的契約：相加會把單精度相位誤差疊起來，每條路徑的界線不能直接拿來用。
2. **低頻有限元素的第一步**：用凍結的上一代跑一個參考解、量它的精度狀態、拍契約。v3 一行都還沒有，是新的一整路。
3. **分格材料**：同一面牆不同格不同阻抗。只是把材料輸入變細，物理不變。

## 決定

採選項 1 當第五段（票 #206）。定義照上一代、不自己發明：總壓力是 63 條路徑壓力的複數相加；
直達能量是直達那一條壓力的模平方；反射能量是 order 大於 0 的 62 條**先複數相加再取模平方**，
兩邊的交叉項刻意不算——這是上一代的定義，v3 照比。上一代是相容性參考，不自動等於物理真值；
這個能量拆法好不好是另一題，要改另立決策。

開工順序寫死：先拿 v3 已有的每條路徑壓力（雙精度）加總，跟上一代兩組答案檔的 totals 逐頻帶量差、
同時量候選界線蓋不蓋得住 → 開 `decision` 票拍總壓力與能量的契約（不能看到候選差異才放寬）→ 才寫 v3 與考卷。
選項 2 排第六段、獨立開票；選項 3 等有人真的需要再排。

## 為什麼

- 一段做得完：參考答案第四段已經入庫（答案檔的 totals 那一塊）、算式只是把已有的 63 條加起來；差的是契約與考卷。
- 這是「一間房聽起來多大聲」的第一個總量，也是計分的前置；有限元素是另一條算路，單獨拍比較乾淨。
- 分格材料只讓輸入變細、不多任何老闆看得到的結果，價值最低。

## 代價

- 第五段做完仍只有一個接收點、一間長方形房；低頻模態那一路要等第六段。
- 總量的契約要多一輪證據與一張決策紙，比直接寫慢一步；但每條路徑的界線相加會疊誤差，不先量就是猜。
- 能量的拆法照上一代，交叉項不算；哪天要換成物理上更對的定義，得另立決策、答案檔也要重跑。

## 拍板

2026-09-12，老闆在票 #204 回「A」；助理建議 A，並建議選項 2 當第六段獨立開、選項 3 等有人需要。
