# 有限元素精度契約補強：規則網格一次元素相容路與正式二次元素路徑

## 問題

`docs/decisions/precision-contract-fem-two-layers.md` 已定兩層有限元素精度契約：① flat（有吸音的平坦案例）在上一代規則網格與 P1（一次元素）上逐頻點對上一代答案不超過 2^-12；②剛性牆在 20 Hz 以下的九個離共振點對解析模態解不超過 2^-10。兩層都擋合併。

正式路徑已改採 gmsh（產生網格的工具）與 P2（二次元素），依 `docs/decisions/legacy-answers-three-roles.md` 屬於第二類，不能把綁在上一代規則網格與一次元素的答案直接當正式路徑門檻；但①是目前唯一直接守阻抗邊界，也就是牆面吸音那一項的檢查。

本紙補強原契約如何落在相容設定與正式路徑，不取代原契約，也不修改原契約的案例、容差或擋合併地位。

## 選項

- **A**：把①降成只記證據的相容紀錄，另做阻抗管解析案例守阻抗邊界；②留在正式路徑，再加自我收斂。
- **B**：新增上一代規則網格加 P1（一次元素）的相容設定，讓①與②原封不動擋合併；正式路徑由②與自我收斂把關，對上一代只留相容紀錄。

## 決定

採選項 B，補強 `docs/decisions/precision-contract-fem-two-layers.md`，不取代它。

- v3 有限元素新增「相容設定」：使用上一代規則網格與 P1（一次元素），只給考卷用。契約①與②在這個設定上照原紙的案例、頻率與容差執行，兩層都擋合併。依 `docs/decisions/legacy-answers-three-roles.md`，這條是第一類，算法相同，只換寫法與精度。
- 正式路徑使用 gmsh（產生網格的工具）與 P2（二次元素），屬於第二類。契約②同樣適用：剛性牆在 20 Hz 以下的九個離共振點對解析模態解不超過 2^-10，擋合併。
- 正式路徑新增③自我收斂：以原網格 P2（二次元素）對較細網格 P2，在 20–250 Hz 比較每個 1/3 八度帶的差。容差另開 `decision`（決策）票拿證據訂；訂好以前，③只記錄、不擋合併。
- 正式路徑仍量對上一代答案的差距並寫進證據，作為相容紀錄，不擋合併。

## 為什麼

- 阻抗邊界，也就是牆面吸音那一項，目前只有①直接在守。③自我收斂只能判斷網格加密後答案是否穩定；阻抗公式若寫錯，例如正負號顛倒，仍可能收斂到錯的答案，不能接替①。
- R1 在同一張上一代規則網格上量到，scikit-fem（有限元素組裝函式庫）組出的剛性矩陣、質量矩陣、邊界矩陣、載荷與接收點內插，對上一代同網格雙精度的相對差都不超過 1.6 × 10^-15。
- flat（有吸音的平坦案例）29 點對上一代答案的最大相對差是 1.436483644 × 10^-4，出現在 12.6000003815 Hz，用掉 2^-12 的 58.838370%；上一代自己開雙精度對答案檔也是 1.436483644 × 10^-4、用掉 58.838370%。相容設定對上一代雙精度的純組裝差只有 6.897881194 × 10^-14，證明差距來自上一代答案的單精度地板，①不必降級。
- 相容設定的剛性牆九點對解析解最大相對差是 7.536309401 × 10^-4，出現在 20 Hz，用掉 2^-10 的 77.171808%，②照原契約守得住。

## 代價

- v3 要多搬一個只給考卷用的上一代規則網格產生器；正式計算不走這個設定。
- ①只證明規則網格加 P1（一次元素）的相容路，不能外推到 gmsh（產生網格的工具）、P2（二次元素）、其他點位或其他阻抗。
- ③容差訂好以前，正式路徑在 20 Hz 以上沒有擋合併的檢查；這段期間只有自我收斂紀錄與對上一代的相容紀錄可查。

## 拍板

2026-09-14，老闆在票 #255 回「B」，助理建議 B。R1 量測後，規則網格加 P1（一次元素）的相容設定守得住原契約，B 的前提成立。證據在 `~/aosr-v3-work/255-regular-mesh/evidence/`。
