# 晚期衰減 T20 的精度契約：每頻帶相對差不超過 2^-20

## 問題

第九段報表把上一代稱為 T60（殘響時間）的 −5～−25 dB 衰減擬合正名為 T20，並要在雙精度下照同一算法重寫。凍結的上一代答案來自參考房三組材料、每組六個頻帶；v3 每頻帶要跟它對到多近，必須在實作前拍板。

## 選項

- **A：2^-20**：每頻帶 T20 對上一代答案的相對差 ≤ 2^-20（約 9.54e-7）；實測最大差 2.24e-7，用掉 23.5%，約留四倍空間給不同機器的單精度捨入。
- **B：2^-21**：每頻帶 T20 對上一代答案的相對差 ≤ 2^-21（約 4.77e-7）；同一實測差會用掉約 47%，較容易受機器或函式庫捨入差異影響。

## 決定

採選項 A。

- 契約：每頻帶 `|T20_v3 − T20_v2| / |T20_v2| ≤ 2^-20`；T20_v2 是凍結的上一代答案。
- v3 算法：用雙精度照上一代定義計算；從同一條晚期混響衰減曲線取 −5～−25 dB 作加權直線擬合，算到 256 階，尾巴的根用精確特徵值，實測差為 0。
- 擬合無效就報錯，不准自動退回其他估法或替代數字。
- 參考答案收 flat、varied、lowabs 三組材料，每組六個頻帶。答案檔入庫留到實作這一刀，不在本紙先放答案檔。

## 為什麼

- 三組材料共 18 格全部成功擬合，沒有一格走上一代的自動退回；只有六面全吸音的控制組六格全退回並回傳 1e-6 秒，v3 對同類無效輸入改為報錯。
- 上一代單精度對雙精度的最大相對差是 2.24e-7；2^-20 約為 9.54e-7，所以用掉比例為 `2.24 × 10^-7 ÷ (2^-20) × 100% = 23.4881024%`，四捨五入為 23.5%。
- 把尾巴改用精確根，並把 256 階增加到 512 或 1024 階，雙精度 T20 的差都是 0；這些近似不是目前的誤差地板。
- 獨立量級對照中，Eyring（依吸音率估算殘響時間的公式）比擬合值差 0.07%～0.6%，每面 4 格或 8 格相對每面 6 格的差約 1e-3；它們都比同算法的數值精度契約粗，不拿來放寬本契約。

## 代價

- 這張契約只守 T20 與上一代同算法的相容性，不替 T30 設容差，也不證明衰減擬合本身的物理正確性。
- 門檻比實測單精度差約寬四倍；這是容納不同機器捨入的空間，任何放寬都要另立決策。
- 參考答案與出身欄位尚未入庫；實作這一刀必須把三組材料六頻帶的答案檔一併交付。
