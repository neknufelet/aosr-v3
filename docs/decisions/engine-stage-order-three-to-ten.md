# 引擎第三到第十段的順序、邊界與交付

## 問題

2026-09-12 到 2026-09-13，老闆分三次拍了引擎第三段之後做什麼：先排第三與第四段，再排第五段，最後一次排定第六到第十段。三張紙其實都在回答同一題，也共同約束後一段何時可以開工。2026-09-21 決策紙份數滿了（票 #412），所以把三張仍有效的段序、交付與停止點合在這裡；舊紙的原文與當時理由留在封存區。

## 選項

- 第三段當時在「先做二階、三階純幾何反射」與「先做振幅和材料吸收」之間選；後者還需要先訂振幅精度契約。
- 第五段當時在「把 63 條鏡像路徑加成總壓力與能量」、「先開低頻有限元素」與「先做分格材料」之間選。
- 第六段之後當時在「維持一段一問」與「一次排定第六到第十段，但段內的新契約與新規矩仍照現行規矩問」之間選。

逐張的完整選項與當時論證在封存區的舊紙；這三張沒有一個共同選項形狀。

## 決定

**第三段先做高階反射，第四段才做振幅與吸收（2026-09-12）**

第二段（票 #181）已讓參考房的直達音與六面一次反射跟參考答案逐位相同。第三段採純幾何方案（票 #187）：沿同一套鏡像法把設定 `max_order`（最大反射階數）長到 2～3，仍使用逐位元幾何契約。振幅與材料吸收排第四段（票 #188），第三段做完才開工。

第四段的開工順序寫死：先用凍結的上一代跑有振幅的參考答案，再開 `decision`（決策）票拍振幅精度契約，材料只開參考房用到的部分，最後才寫 v3。這個順序保留「先凍結鏡像清單，再把能量掛上去」的算法邊界。

**第五段做鏡像法總壓力與能量（2026-09-12）**

第四段（票 #194）完成三階 63 條鏡像路徑、六個頻帶、兩組材料與逐路徑振幅後，第五段採總量方案（票 #206）。總壓力是 63 條路徑壓力的複數相加；直達能量是直達那一條壓力的模平方；反射能量是反射階數大於 0 的 62 條路徑先作複數相加，再取模平方。直達與反射兩邊的交叉項刻意不算，這是上一代定義；v3 把上一代當相容性參考，不把這個能量拆法自動當成物理真值。要改拆法，另立決策。

第五段的開工順序也寫死：先拿 v3 已有的每條雙精度路徑壓力加總，對上一代兩組答案檔的總量逐頻帶量差，也量候選界線能否蓋住；接著開 `decision`（決策）票拍總壓力與能量契約，不准看到候選差異後才放寬；最後才寫 v3 與考卷。低頻有限元素排第六段、獨立開票；分格材料等有人真的需要再排。

**第六到第十段一次排定（2026-09-13；2026-09-18 修訂計分資料的說法）**

採一次排定方案，之後不再逐段詢問做哪一個；每段仍走「參考答案 → 契約 → v3 → 考卷 → 找碴 → 雲端綠 → 合」的流程。段序與邊界如下：

- 第六段是低頻有限元素的參考解與契約：用凍結的上一代對參考房算低頻壓力，採上一代的細頻率軸並到 250 Hz 上限；另加剛性牆子案例，以長方形房解析模態解作獨立真值，同時量上一代與 v3 離真值多遠，契約另拿證據拍板。
- 第七段是有限元素的 v3：照第六段契約施工；採哪一個數值函式庫另作一張決定，在開工前拍板。
- 第八段是晚期混響能量：走上一代的 ART（聲線追蹤晚期混響）路徑並含 Eyring（艾林）修正，依序做參考答案、契約與 v3。
- 第九段是三路接合與物理量報表：有限元素與幾何路用 Schroeder（施羅德）頻率、半個八度平滑並在能量域相加；鏡像法與晚期混響靠能量衰減自然交接。交付一個接收點逐頻帶的直達、反射、晚期與接合後總能量，以及 T60（六十分貝殘響時間）與 Schroeder（施羅德）頻率。只做頻率域，不做脈衝響應。
- 第十段是分格材料與多接收點：同一面牆可有不同格、不同阻抗，並支援多個接收點。
- 第十段之後另排新的計分、最佳化、脈衝響應與非長方形房。

上一代計分不接：上一代分數不作參考答案，也不訂相容契約；新的計分是產品設計，另作決定。第九段報表在 2026-09-18 由 `quality-evaluation-seven-categories-three-layers.md` 修訂為計分要吃的「第一批評估資料」，不再稱為「全部物理量」；第九段既有頻率域交付範圍不變，其餘資料能力按那張紙的缺口分項另排。

## 為什麼

- 第三段不需要新契約，一段就能把幾何路長到夠用；振幅容差需要證據，分開拍比較乾淨。
- 第五段只需把已入庫答案中的 63 條路徑加總，是「一間房聽起來多大聲」的第一個總量，也是計分前置。有限元素是另一條算路；分格材料只把輸入變細，當時沒有新增老闆看得到的結果。
- 第六段以後的施工模式已穩定，不確定性只剩有限元素是否跑得動、兩條算路怎麼接、計分對什麼。上一代原始碼顯示參考房在 250 Hz 約有八千個未知數，CPU（中央處理器）跑得動；接合按房間算的 Schroeder（施羅德）頻率並在能量域進行；計分吃逐頻帶能量與頻率響應。
- 先做晚期混響再接合，可讓接合只寫一次；上一代計分反覆改過，從物理量重建比先鎖住再拆乾淨。

## 代價

- 第三段完成時仍聽不出材料差別，第一張帶強弱的反射表要等第四段；第四段之前還多參考答案與契約兩個步驟。
- 第五段完成時仍只有一個接收點與一間長方形房，低頻模態要等第六段。總量契約多一輪證據與一張決策紙；能量拆法沿用上一代並排除交叉項，日後若改成別的物理定義，要另立決策並重跑答案檔。
- 第六到第十段的順序是當時排定的；第六段若證明有限元素形狀不同，必須回來改紙，不能默默換序。第九段只交頻率域，脈衝響應要另排；有限元素細頻率軸會讓答案檔變大，上一代也要多跑幾分鐘。
- 合併帶來的代價：這些段序在機器眼裡變成同一題；以後任何一段要翻案，都必須用新紙取代整張，並把其餘仍有效的段序與邊界再搬一次。
