# 低頻有限元素的精度契約：有阻尼案例對上一代 2^-12，加剛性牆二十赫茲以下對解析解 2^-10 的物理健檢

## 問題

第六段（票 #213）第 1 段量完：凍結的上一代對參考房跑低頻有限元素（P1 四面體、每波長六格、27×18×14 網格、
250 Hz 上限、單精度稠密解），正式軸 29 點、1 Hz 細軸 241 點、精度地板 58 點。要拍 v3 跟它對到多近、拿什麼當真值。

## 選項

1. **兩層**：①相容契約：flat 案例每個頻點對上一代 ≤ 2^-12；②物理健檢：剛性牆 20 Hz 以下離共振九點對解析模態解 ≤ 2^-10。
2. **只有相容契約**：只做①，剛性對解析解只記證據。

## 決定

採選項 1。
- ①相容契約：v3 對上一代 flat 案例（六面 4·ρc）每個頻點的複數壓力，|p3 − p2| ≤ 2^-12·|p2|；網格 27×18×14、P1 四面體、
  每波長六格、頻率軸照上一代正式軸（1/6 八度、10 Hz 起、≤250 Hz 共 29 點）。
- ②物理健檢：剛性牆（γ=0）、20 Hz 以下的九個離共振點（上一代的挑法：每個子頻帶取離所有本徵頻最遠的點），
  v3 對解析模態級數相對差 ≤ 2^-10。
- 參考答案入庫 flat（29 點）與 rigid（正式軸 29 點加離共振 29 點）；細軸與精度地板留在外部證據。
- 求解用哪個數值庫是第七段開工前另一張決定。不准之後放寬。

## 為什麼

- ①的地板量過：上一代單精度對同一條鏈開雙精度，58 點相對差中位數 6.3e-6、最大 1.4e-4（12.6 Hz）；2^-12 約 2.4e-4，最差用到 59%。
- 剛性牆對解析解只在 20 Hz 以下有意義（最大 7.5e-4，2^-10 用到 77%）；再往上 P1 網格把共振挪約 1%，無阻尼的房在共振旁邊發散，
  正式軸上多數點離最近本徵頻不到 1%，差從幾成到兩百倍。找碴席確認是物理與網格不是腳本錯（雙精度一樣爆、網格加密離共振點 O(h²) 收斂）。
- ②是唯一不靠任何程式的真值，只有九個點，成本小；沒有它，v3 跟上一代一起錯也看不到。

## 代價

- ①是相容契約，只證明 v3 算得跟上一代一樣，不證明有限元素在這個網格下夠準；網格精度是另一題。
- ②只蓋 20 Hz 以下；共振附近的準確度沒有契約守，只有 1 Hz 細軸的證據可查。
- 上一代的正式軸太粗看不到模態，軸拉成設定另有票 #218。
