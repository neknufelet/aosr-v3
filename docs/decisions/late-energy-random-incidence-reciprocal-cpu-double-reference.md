# 晚期混響用無規入射吸音率、形狀因子守互易；雙精度是中央處理器參考，顯卡單精度另立尺

## 問題

外部物理審查（票 #303、#304、#306）指出晚期混響照上一代用垂直入射吸收率 `1 − |r|²`，與型錄無規入射反推的阻抗（`catalog-absorption-random-incidence-paris-inversion.md`）
定義不一致；形狀因子逐列正規化後破壞面積加權互易 `A_i F_ij = A_j F_ji`。修任一項都會離開上一代答案，舊契約紙規定每頻帶相對差 ≤ 2·1e-4 擋合併。

2026-10-28 換紙的原因只有一條：前紙決定第 6 條寫「解法照舊雙精度直接解」，而 `docs/decisions/optimization-stages-room-with-positions-then-layout-then-zoned-materials.md` 表二把第三階段的晚期混響定為 JAX（自動微分計算庫）在顯卡上用單精度，那張紙的代價段寫明要換這一條（#562）。其餘五條照前紙原文。

## 選項

- **A：改無規入射、一起修互易**：上一代答案降為相容紀錄，改用獨立物理性質擋合併。
- **B：維持上一代定義**：三件都不動，保留舊契約。

## 決定

採選項 A。

1. 每個牆面格的吸收率用 Paris 無規入射 `α_d = 2∫₀¹ [1 − |(ζμ−1)/(ζμ+1)|²] μ dμ`，ζ 為正規化複數阻抗，以 256 點 Gauss–Legendre 數值積分；ζ 實部不大於 0 或非有限報錯。
   源項、正規化與 Eyring 修正裡用到的平均吸收率同樣換成 α_d。
   2026-10-16（#703，`stage-two-furniture-v1-boxes-single-bounce-approximate-ranking.md` 第 23 條）起有家具時，每格先照上面（或 #309 的構造、實測表）得出牆自己的吸收率 α，再換成 α＋(1−α)·ε，ε＝A_f ／ Σ S_j·(1−α_j)（對每一格加總，S_j 是格面積），A_f 是家具整件吸音量；也就是每一格的反射率乘同一個 (1−ε)，總吸收剛好多 A_f。
2. 形狀因子：中心點近似原始值 → 交換矩陣 `G_ij = (A_i F_ij + A_j F_ji)/2` → 反覆 `G ← diag(d) G diag(d)`、`d_i = sqrt(A_i / Σ_j G_ij)`，
   直到列和最大偏差不再嚴格下降為止（沒有差值容差，也沒有迭代上限）→ `F_ij = G_ij / A_i`。
3. 報表的 Eyring T60 與 f_s 用同一個 α_d。Eyring 常數 0.161 本紙不動。2026-10-16 起有家具時兩者也吃同一個 A_f 與同一個 ε（#703）。
4. 上一代晚期能量答案（`blueprint/reference_art_*.json`）依 `legacy-answers-three-roles.md` 降為第二類：答案檔、比較器與命令列差距表保留，照量、照留、不擋合併。
5. 擋合併的獨立性質，相對差界線 `2^-30`，常數住在晚期混響模組：形狀因子互易與列和（多種每面格數、非立方房）；
   均勻材料房間 Eyring 修正前的能量等於用 α_d 的 Sabine 擴散場公式；穩態吸收功率總和等於源功率；同阻抗分格等於整牆；
   複數 α_d 對 4096 點數值積分真值。
   2026-10-16 起五項性質加家具案例（#703）：均勻牆面時每格的 α＋(1−α)·ε 仍然同值，Sabine 那一項的平均吸收率是 (S·α_d＋A_f)/S；穩態吸收功率總和含家具那一份；同阻抗分格每格同一個 ε、仍等於整牆。界線照舊。
6. 網格固定每面 6 格。2026-10-28 改寫這一條（其餘五條照前紙）：
   - numpy（陣列運算函式庫）雙精度直接解（`src/aosr/physics/late_energy.py`）是中央處理器上的參考，報表、搜尋與上面五項性質都照舊走它。
   - 同一套公式另有 JAX 版（`src/aosr/physics/late_energy_jax.py`）：輸入每面每頻吸音率，對吸音率可微、可整段編譯（jit）；精度跟輸入走，雙精度進就整條雙精度、單精度進就整條單精度。跟材料無關的分格與形狀因子借 numpy 版那一份、雙精度先算好當常數，不另寫第二份。
   - JAX 版在中央處理器雙精度對 numpy 版的尺是 `late_energy_jax_vs_numpy`＝`2^-36`（相對差，逐頻 ᾱ、原始能量、Eyring 比值、晚期能量四格，工程暫定），住在 `blueprint/precision_contracts.toml`，帶變異考卷。
   - 顯卡單精度另立一把尺，等晚期混響接進第三階段計算時用顯卡實量再登記；這張紙不先訂數字，也不准借上面那一把。

## 為什麼

- Eyring 與擴散場理論本來就用無規入射吸音率；晚期混響是漫射場模型，用垂直入射會把吸收低估。
- 參考房量測（repo 外 `~/aosr-v3-work/art-trio/`、`~/aosr-v3-work/306-art/`）：改 α_d 後晚期能量 flat −4.20 dB、lowabs −3.41 dB、varied −4.04～−4.21 dB；
  T20 flat 0.105 → 0.069 s、lowabs 0.268 → 0.160 s；f_s flat 76.4 → 61.8 Hz、lowabs 121.9 → 94.2 Hz。
- 對照 30 階非同調鏡像法反射能量：晚期能量用垂直入射時高出 flat +2.64／lowabs +3.00 dB，用 α_d 時為 −1.56／−0.41 dB。
- 互易：現行最差 24.96%、中位 4.22%；修正後 2.8e-16 等級。對參考材料晚期能量影響最大 0.0068 dB（varied），均勻材料看不到；與 α_d 一起改只離開上一代答案一次。
- 五項性質實測最大相對差 4.2e-15（分格等於整牆），界線 2^-30 只擋數量級錯；256 點對 4096 點最大 1.4e-13。前例是晚期衰減 T30 性質考卷與 FEniCS 契約。
- 決定第 6 條（2026-10-28，中央處理器實量，三份凍結題目加兩組固定種子隨機吸音率，考卷 `tests/engine/test_late_energy_jax.py`）：JAX 雙精度對 numpy 版逐頻最大相對差 1.47e-14（Eyring 比值，隨機那一組），`2^-36`≈1.46e-11 留約千倍給換機器；公式一抄錯就是 1e-8 以上，擋得住。
  單精度對雙精度：晚期能量最大 3.8e-7、對吸音率的梯度最大 4.6e-7、梯度沒有符號翻轉，跟三階段紙「晚期混響梯度 2.3e-7」同一個量級；這是中央處理器上的單精度，顯卡另量。
  梯度對 numpy 版中央差分（步長 1e-5）最大相對差 9.2e-11。jit 前後不逐位相同，差到最後一位一格（2.6e-16）。

## 代價

- 報表的晚期能量、T20、T30、f_s 全部變動，跟上一代答案差到 3～4 dB、三到四成，不再能用上一代答案抓 v3 的小錯。
- α_d 是漫射場平均，格與格之間的實際入射角沒有逐對計算；分格材料差異大時仍是近似。
- 有家具時，家具那一份照各格剩下的反射比例分到每一格，看不出家具在房裡哪裡；分法沒有獨立真值，只守總量（2026-10-16，#703）。
- Eyring 常數 0.161 與衰減換算 24·ln(10)/c 差 7.07e-4，本紙未統一（票 #306 留言）。
- 鏡像法三階與晚期混響的能量收支（票 #303）本紙未處理，改完後重量再設計。
- 吸音率跟材料有關的那一半有 numpy 與 JAX 兩份實作；兩份靠 `late_energy_jax_vs_numpy` 綁住，改一份忘了另一份會紅。JAX 版在編譯裡無法依數值報錯，吸音率有限且在 [0,1] 由呼叫端負責。
- 單精度遇到極小吸音率會失效（2026-10-28 外部審查指出，#562）：6×4×3 m 六面同一個 1e12 Pa·s/m、125 Hz、每面 6 格得 α＝3.2928e-9，單精度算 1−α 時 α 被捨掉、反射率恰為 1、耗散消失，I−R 近奇異，線性解照樣回有限的負能量（約 −4.5e8；雙精度與 numpy 版都是約 +1.41e8），只看有限性抓不到。JAX 版因此多回逐頻布林 `dissipation_resolved`：任一分格 α＞0 但 1−α 在工作精度下不小於 1（吸音被捨掉）、或晚期能量非有限或不大於 0，就是 False；α 恰為 0 的剛性面是合法輸入、不算；不夾吸音率下限、不把能量截成 0，原始數字照回，呼叫端要自己查這一格。
  旗標只認「分不分得開」，不保證準：中央處理器單精度實量，α＝1e-7 晚期能量比 numpy 版低 13.5%、1e-6 低 1.1%、1e-3 差 2.4e-5，旗標都是 True。
- 顯卡沒在這一步量：顯卡上的單精度矩陣乘法有平台預設降精度的坑，JAX 版的乘法已指定最高精度，但線性解在顯卡上的誤差、跟顯卡單精度的尺都還沒有數字。
