# 砍掉「文字格式一致」這張卡，單字母標籤改為命名慣例

## 問題

候選卡 `text-format-consistent` 原本管四件事：換行一律 LF、不准繁簡混用、不准字母加數字當代號、不准單字母標籤。找碴席逐條對回 v2 的 66 筆事故後，前三條零血債，第三條還會誤咬正常文件（lint 規則編號 `F401`、聲學指標 `T20`、健檢編號 `H01`）。只剩單字母標籤跟 v2 有一點內容接觸（A／B／C 口誤），沒有造成事故。

## 選項

1. 砍到只剩「單字母標籤」一條，仍立卡。
2. 整張砍掉，「不用單字母標籤」寫成命名慣例，不當會回紅的檢查。

## 決定

選項 2。命名慣例一句：**標籤、選項、席位不用單字母（A／B／C、E／F／G），用能自解釋的短詞。** 放在這張紙，之後有寫作規範再搬。

## 為什麼

一張卡要有牙。這張沒東西可咬，立了就是 v2「規矩多但沒人守」的重演。v2 自己在這條上翻過案（1.7.0 全禁 → 1.9.0 收斂），再立一次是重演同一次心證翻案。

## 代價

換行符號若真的出問題，用 `.gitattributes` 一行設定處理，不佔卡。

## 拍板

老闆，2026-09-09 對話：「砍」。
