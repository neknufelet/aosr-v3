# 頻率軸：細軸到 8000 Hz 帶上緣、報表含 8000 Hz 帶、帶內密軸 0.5 Hz 一視同仁

## 問題

本紙把 2026-09-22 同日拍的三題收在一處，不改任何決定。跟舊紙字面不同、要靠判斷的地方（兩處出處更正、幾處數字與條件更正）逐條列在合併請求內文，紙內照更正後的寫法。原本的題各是：

1. **細軸上限**（票 #347）：音色的診斷與起伏計分範圍已拍到 8000 Hz，音色資料契約又要求計分範圍外加平滑半窗；但幾何路共用細軸只到 4000 Hz 八度帶上緣。若順手把 8000 Hz 加進報表帶清單，鏡像法 0.5 Hz 密軸會多一大段成本，那是另一題。
2. **報表加不加 8000 Hz 帶**（票 #437）：細軸已到 8000 Hz 帶上緣，報表中心仍停在 4000 Hz。加一帶會讓密軸多 11314 點，也會讓殘響開始評先前拍下的 8000 Hz 目標，要先知道成本再拍。
3. **帶內密軸多密**（票 #440）：原本想依頻帶放寬密軸間距、縮短鏡像法時間；最初的 A／B 判讀把 #302 的證據讀反，把「細軸在高頻偏掉」誤當成「高頻可以少取樣」。要先量出密軸在哪裡收斂，才能決定省哪一段。

0.5 Hz 密軸的原始決定在 `stage-nine-reflection-order-is-a-setting.md` 第 6 條（票 #302 回 A），本紙不取代那張紙。

## 選項

舊紙整理的選項（舊紙全文在封存區）。字母是舊紙自己編的，跟票上或對話當時問的 A／B 不一定相同，見拍板段：

- 細軸上限：A 細軸到 8000 Hz 帶上緣、報表帶清單仍到 4000 Hz，兩者脫鉤；B 兩者一起加到 8000 Hz，當時就承擔新增密軸點的成本。
- 報表帶：A 維持 125～4000 Hz 六帶，8000 Hz 只供音色細軸；B 加 8000 Hz 成七帶，殘響目標與同帶密軸一起生效。
- 密軸：A 高頻帶用較粗間距，或退回每八度 24 點的細軸；B 所有報表帶維持 0.5 Hz、不分帶；C 先量 0.25、0.5、1、2、5 Hz 與細軸，再依量測決定。

## 決定

### 一、細軸上限與脫鉤（#347 採 A）

1. `GEOMETRIC_AXIS_UPPER_HZ`（幾何路細軸上限）是 `8000·√2` Hz，正式 1/24 八度細軸取不超過這個上限的最後一點（#347 當時 220 點，末點 11166.8 Hz）。這一條修正 `stage-nine-reflection-order-is-a-setting.md` 第 6 條原本的上緣。
2. 細軸上限不再由最後一個報表帶反推（脫鉤）。當時報表帶清單仍是 125～4000 Hz；同日稍後由第二題加了 8000 Hz，脫鉤這一條不變。
3. `timbre_balance.ripple_range_hz`（音色起伏計分範圍）上緣是 8000 Hz。起伏平滑寬度是零，所以不另加半窗；傾斜的 1/3 八度平滑半窗仍完整落在細軸內。
4. 本紙不動 `timbre_balance.tilt_fit_range_hz`（音色傾斜擬合範圍，80～4000 Hz）。它的值住品質登記簿（測試基線，正式值等 #358）；音色傾斜容許帶 1.0 的推導以這段範圍為前提，推導寫在 `timbre-tilt-target-tolerance-worse-reference.md`。要動得老闆另拍。
5. 本紙不改有限元素路的 300 Hz 上限與全部有限元素頻點（當時 94 點）。
6. 能力表 `src/aosr/config/data/capabilities.toml`：
   - 宣告整條細軸的列，`frequency_hz` 上限寫細軸末點取整 11166。#347 當時是五列（三路報表三種材料形式、型錄反推、音色評估器），由 5583 改成 11166。
   - 逐帶入口 `late_energy` 那列寫報表帶範圍：#347 當時仍是 125～4000；第二題加帶時改成 125～8000，由考卷 `test_report_bands_8khz.py::test_late_energy_capability_row_spans_exactly_the_report_band_centers` 守。
7. 評估器邊界：`src/aosr/scoring/timbre.py` 的半窗在平滑寬度 0 時回 0。不平滑就沒有視窗、也就沒有捨入護欄；否則依賴上界會比計分上界高一根頭髮，資料剛好量到 8000.0 Hz 的曲線會被判「計分範圍有缺」。

### 二、報表八度帶納入 8000 Hz（#437 採 B）

8. `GEOMETRIC_REPORT_OCTAVE_CENTERS_HZ`（幾何報表八度帶中心清單）在 4000 Hz 後加入 8000 Hz，共七帶；報表與晚期衰減照它產帶。
   - 殘響評估讀品質登記簿自己那份中心清單，兩份由考卷 `test_reverberation_cost.py::test_formal_reverberation_interval_is_the_decided_one` 綁成集合相等。
   - 晚期混響命令列的帶跟著輸入檔。
9. 8000 Hz 殘響 T20（衰減 20 dB 推估的殘響時間）目標是 0.25～0.6 秒：名義值 0.425 秒、容許量 0.175 秒。區間內不罰，低於 0.25 秒或高於 0.6 秒才罰。這個區間是 #430 拍的，本題讓它生效。
10. 新增帶的帶內密軸跟其餘六帶一樣用 0.5 Hz；總點數 11137→22451，多 11314 點。
11. 1/24 八度細軸與有限元素頻點（當時 220 點、94 點）本紙不改，也不因新增報表帶改動。
12. 上一代答案只有六帶，仍照原答案的頻帶比較；新增帶要明說沒有上一代答案，不算比較錯誤。

### 三、帶內密軸 0.5 Hz 一視同仁（#440：先量，量完維持原樣）

13. 量完維持 0.5 Hz：所有報表帶一視同仁，不分帶、不放寬。
14. 量測條件：六個場景，都是參考房 6×4×3 m；交接階數 K=3 與 K=8。數字（工作區 440-dense-axis-cap 的量測腳本與原始輸出）：
    - 0.25 Hz 對 0.5 Hz 的最大差 0.014 dB；1 Hz 最大 0.015 dB。
    - 2 Hz 與 5 Hz 的最大差：K=8 下 0.071／0.064 dB，K=3 下 0.045／0.042 dB；最壞都在 125 Hz 帶。
    - 每八度 24 點的細軸，不能取代密軸的帶內平均：
      - 六帶裡細軸對 0.5 Hz 的差，K=3 是 −0.638～+1.316 dB，K=8 是 −0.711～+1.197 dB。
      - 4000 Hz 帶在 K=3 下，flat 1.201 dB、lowabs 1.316 dB（#302 那兩個場景的復現）。
      - #302 記的 +0.74／+0.72 dB 是「補干涉項前後」的差，這裡量的是「24 點對 0.5 Hz」的差，量法不同、方向一致。
    - 加 8000 Hz 帶後對該帶補量（K=3、六個場景）：0.25／1／2／5 Hz 對 0.5 Hz 的差都在 0.001 dB 內；細軸 24 點偏 0.50～1.13 dB。
    - 密軸六帶 K=3 約 1.7 秒、K=8 約 31 秒；七帶 K=3 實測 3.4 秒。完整報表時間主要花在晚期混響與有限元素，不是 K=3 的密軸。
    - 0.5 Hz 夠不夠密只在參考房量過。
15. 音色計分讀細軸逐點資料，殘響計分讀晚期衰減擬合，兩者都不經密軸。

## 為什麼

- **細軸到 8000 Hz 帶上緣**：音色評估已拍到 8000 Hz。把細軸拉到該八度帶上緣，可以同時包住 8000 Hz 計分範圍與傾斜平滑所需的外側半窗。報表帶清單當時不動，就不會在還沒報成本、另行拍板以前，讓鏡像法的 0.5 Hz 密軸跟著擴張。
- **報表加 8000 Hz 帶**：知道成本之後（鏡像法多約 1.7 秒與一次晚期衰減擬合），決定報表涵蓋 8000 Hz。殘響的 8000 Hz 目標早已在 #430 拍下，只是等晚期混響真正產生這一帶。
- **密軸 0.5 Hz**：0.5 Hz 對 0.25 Hz 的最壞差只有 0.014 dB，已足以視為收斂，再加密沒有相稱收益。反過來，細軸在 4000 Hz 已偏超過 1 dB，證明不能先假定高頻不需要可靠的帶內平均。加 8000 Hz 帶後補量是同一結論，不因高頻帶另設較粗規則。

## 代價

- 幾何路逐點計算多 24 點（196→220）。新增的 24 點落在 5657 Hz 以上，不進當時任何一個報表八度帶，所以當時六帶的帶內平均、交接權重、逐帶殘響全部逐位不變；吃到新高頻的，是走報表逐點表進音色評估器的那一路。
- 對外看得到的兩個變化：
  - 正式報表的音色不再掛「覆蓋不足」旗標，因為細軸已蓋滿 20～8000 Hz 的診斷範圍。
  - 殘響 4000 Hz 帶的模型驗證狀態從「沒查過」變成照抄能力表的「試驗中」：能力表上限 11166 已包住該帶上緣 5657，之前的 5583 沒包住。
- 8000 Hz 帶的上緣 11314 Hz 高於能力表宣告的細軸末點 11166 Hz，所以殘響對這一帶的模型驗證狀態是「沒查過」，不是照抄表上的「試驗中」。兩者都算未驗證，只差標籤；#347 之前的 4000 Hz 帶（5657 對 5583）也是同一形狀。要不要改判法另題。
- 鏡像法 K=3 六帶約 1.7 秒、七帶 3.4 秒。一份完整報表（參考房、單緒）實跑 5 分 13 秒，跟六帶那次的 5 分 27 秒差在機器負載的雜訊內。
- 型錄只到 4000 Hz 或 8000 Hz 時，新增的高頻細軸點照既有決策用最近端帶平坦延伸，並標記為延伸資料，不冒充量測值。
- 既有上一代答案檔不重錄，所以 8000 Hz 沒有跨代數值比較；新帶仍有產品計算與目標區間考卷。
- 合成一張的代價：以後這三題任何一題重決，都要取代整張合併紙（`one-decision-one-paper-may-merge-many.md`）。傾斜擬合範圍與有限元素點數寫成「本紙不改」，就是為了不讓 #339、#435 改它們時連帶取代這張紙。
