# 振幅的精度契約：容差跟著相位角長，常數取單精度四格

## 問題

第四段（票 #188）第一步做完：上一代對參考房（三階 63 條、六個頻帶、兩組材料）算出每條路徑的反射乘積與壓力，
另外只用標準庫雙精度獨立算一次。發現上一代的振幅是**單精度**（complex64）算的，ω 與 τ 各被切成 float32 一次，
所以幾何那張「逐位元相同」的契約在振幅這裡做不到，要另訂。

## 選項

1. **容差跟著相位角長**：反射乘積每分量絕對差 ≤ 2^-21（單精度四格）；每條路徑的壓力相對差 ≤ 2^-21·(ωτ+1) + 2^-21/|反射乘積|。
2. **一刀切**：反射乘積絕對差 ≤ 2^-21；壓力相對差 ≤ 2e-4，全頻率同一個數。

## 決定

採選項 1，範圍是第四段的**每條路徑**的反射乘積與壓力（ω=2πf，τ=到達時間）。壓力的相對差以複數差的模除以參考值的模計。
- 直達路徑的反射乘積必須恰等於 1，不設容差。距離與到達時間照 `precision-contract-geometry-bit-exact` 逐位元。
- 總壓力（把 63 條相加）與能量的比法等第四段實作時另訂：相加會把相位誤差疊起來，要另拿證據。
- 不准之後放寬；等不了另立決策。

## 為什麼

- 誤差有公式，不是噪音：實測壓力的相對差 ≈ 7e-8 × ωτ（ω、τ 各切一次 float32 的相對誤差加起來），三階路徑再加上反射乘積連乘的單精度誤差。
  界線照這個形狀訂，低頻緊（125 Hz 直達約 4e-6）、高頻鬆到該鬆的程度，換更大的房或更高的頻率自己跟著長，不用改數字。
- 實測 63×6×2 格，最壞只用到界線的 22%（反射乘積 16%）。一刀切 2e-4 在低頻比真實差鬆 400 倍，藏得住 bug，大房間高頻又會不夠。

## 代價

- 界線是一條公式不是一個數，看的人要多想一步；考卷要帶 ω、τ 一起算。
- 常數取四格是留餘裕的選擇，不是推導出來的；若哪天有正當理由差超過，要走決策不能調常數。
