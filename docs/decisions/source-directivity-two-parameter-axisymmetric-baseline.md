# 喇叭指向性第一版用兩參數三維旋轉對稱近似，低頻全向、鏡像法逐路徑乘、晚期乘同一模型的功率倍率

## 問題

v3 三段計算（低頻有限元素、鏡像法、晚期混響）都把喇叭當全向點聲源；報表路徑表與反射評估寫死「未含喇叭指向性」（#504）。最佳化要比較靠牆、近場的擺法（#500、#502），喇叭往側牆、背牆、桌面送出多少聲音直接影響反射類評分，沒有指向性時那一類的排名只能當方向參考。

上一代有一套解析式模型（v2 內部代號 D13a）：圓形活塞裝在無限剛性障板上的遠場指向因子，對稱延伸到後半球，再乘一條經驗性前後比，整體正規化成總輻射功率跟全向一樣；整個頻段都用同一顆低音單體的半徑。這讓高頻往正後方送的聲音比往側面多（側面有零點），正前方也被正規化放大（#505 查證）。

## 選項

1. 照搬上一代的活塞公式與總功率正規化。
2. 一個參數、從全向漸變到心形的曲線：功率最多只能比正前方低約 4.77 dB，純心形時正後方為零（主對話重算：功率比＝(1＋k＋k²)／3）。
3. 一個參數的指數型 D＝exp[−β(1−cosθ)]：對得上 30°、60°、90° 與指向指數，對不上 250 Hz–2 kHz 的正後方（真喇叭的後方比公式平）；把指向指數對準時，500 Hz–4 kHz 的正後方會被算小聲 3.2～4.3 dB。
4. 兩個參數：指數型加一個功率下限。
5. 接喇叭實測的全角度資料（Spinorama）或模擬單體、分頻器、箱體：這一版不做。

## 決定

採 4，當第一版的工程基線。拍板與覆核的來源見「拍板」。

- **模型**：以喇叭軸線為中心的三維旋轉對稱近似。θ 是一條路徑「離開喇叭的方向」跟喇叭軸線的三維夾角（含俯仰）。聲壓倍率 D(f,θ)＝√[(1−ρ(f))·exp(−2β(f)(1−cosθ))＋ρ(f)]，正前方逐位為 1；功率倍率（對同樣正前方聲壓的全向聲源）g(f)＝(1−ρ)(1−e^{−4β})／(4β)＋ρ，β＝0 時為 1。上下方向暫時沿用同一條曲線，尚未獨立驗證。
- **預設參數**：β(f)＝3.2／[1＋(4000／f)^0.67]；ρ 換成分貝＝−45／[1＋(2550／f)^1.12]。取自六款常見箱式監聽（兩音路與三音路，含同軸、波導）公開 CTA-2034 原始數值檔的中位數，水平面、1/3 八度帶平均；指向指數取「正前方減總聲功率」，不是 CTA 的 Sound Power DI（聆聽窗減總聲功率）。參數住在一份登記簿、專案可以覆寫，同一輪比較固定用同一套；不為了壓低擬合誤差再加參數。
- **允許的參數範圍**：每個頻率的 β 在 0 到 10、功率下限在 −80 dB 到 0 dB 之間；超出範圍就拒收。
- **各段怎麼用**：低頻那一段（有限元素）維持全向。鏡像法那一段（直達與每條反射）把每條路徑的複數聲壓乘上 D，乘在相加之前；方向用離開方向（長方形房照每一軸反射次數的奇偶翻轉鏡像源到接收點的向量），不是路徑表記的到達方向。晚期混響那一段的能量乘同一模型的 g(f) 一次；T20／T30 由另一條自我正規化的衰減計算給，不受影響。
- **基準**：正前方一公尺處聲壓幅值為 1，不再用「總功率不變」的正規化；輻射功率是全向的 g(f) 倍。
- **朝向**：場景給一個對準點（每個候選預設是它的主位，可以手動換），每支喇叭各自算自己的軸線＝單位化（對準點減喇叭位置）；同一候選的周圍座位不轉向。第一版不讓最佳化搜尋朝向。
- **聲源模型必填**：報表輸入、各層求解函式、評估結果都明寫聲源模型的種類（全向、兩參數近似、上一代相容對照），沒有預設值；「產品預設＝兩參數近似、對準主位」只住在一支函式裡。兩個聲源模型不同的候選不同表：評估結果多一格聲源模型身分（種類、模型版本、參數），排名的比較身分照抄；殘響那一類明寫不帶這一格。
- **上一代相容對照**：上一代活塞公式做成第二種、非預設的聲源模型種類，只拿來做相容對照，不是新模型要追上的真值。
- **精度契約** `source_directivity_power_ratio_consistency`＝2^-30（相對誤差）：只用在「功率倍率公式解對獨立數值積分」這一項數值一致性檢查，不代表喇叭或房間的仿真精度。考卷含預設值與允許範圍的邊界，並用典型錯法確認考卷真的會紅。
- **施工分四刀**：模型本體與登記簿；報表輸入必填聲源模型（先只收全向，數字逐位不變）；評分層讀聲源模型與同表身分；真的乘上 D 與 g、能力表標試驗中。

## 為什麼

- 平滑、沒有零點、參數少：不讓最佳化拿「一顆大單體的側面零點」這種未驗證的模型細節去換漂亮分數。
- 兩個參數夠用、一個不夠：對六款中位數，一個參數在中頻把正後方算得太小聲，兩個參數在 250 Hz–4 kHz 逐頻擬合每格都在 0.5 dB 以內。
- 正前方固定比總功率固定直觀：房間造成的峰谷、反射保留在座位上，聲源本身的差異集中在功率倍率。
- 必填不設預設：上一代出過「功能沒接到正式管線、靜默無效」與「缺鍵的夾具改了意思」兩種事故（v2 事故 L31、L55）。

## 代價

- 這是工程近似，不是任何一款喇叭。擬合誤差只記成「預設曲線對六款中位數表（125 Hz–8 kHz 七個頻率 × 30°、60°、90°、180° 與指向指數五個量，共 35 格）的均方根」：對未取整的中位數 0.68 dB、對取整到 0.1 dB 的表 0.69 dB，最大 2.2 dB（8 kHz 正後方）；不是任何一款喇叭、上下方向或完整三維聲場的誤差保證。
- 只用了水平面資料；上下方向（地板、天花板反射離開喇叭的方向）是假設。
- 「越往後越小聲」是模型的設計條件：六款裡有 4 格（共 48 格）正後方比側面大聲 1 dB 以上，模型對不上。
- 250 Hz 的真實喇叭已經不是全向（中位數正後方約 −2.3 dB），低頻那一段仍全向；兩段交接處要量過，量出台階再另外處理。
- 晚期那一份只用一個功率倍率：鏡像法前幾階被散射掉的能量乘的是房間平均的 g，不是逐路徑的 D²；「同樣總功率、朝吸音牆或朝硬牆發聲」的差別沒有處理。
- 所有場景指紋會變（聲源模型進指紋），之前存下的報表與評估結果載不進新格式；交換格式版本另由 #411 記。
- 精度契約的考卷只證明公式照定義跑、數值積分跟公式解一致；不保證所有參數都通過，也不保證抓得到所有公式錯誤。

## 拍板

**老闆原話**（2026-09-26，老闆自己打的字，#505 留言）：

> 我選 A，兩參數版本先作第一版工程基線，不再擴大成完整喇叭仿真。
>
> 請明確把它定義成三維旋轉對稱近似：每條路徑使用出發方向與喇叭軸線的三維夾角，上下方向暫時沿用同一條曲線，並標示尚未獨立驗證。殘響功率倍率由同一個模型計算，不另套不一致的倍率。
>
> 固定預設值前，確認量測資料的 DI 是「正前方減聲功率」，還是 CTA 的「聆聽窗減聲功率」；若是後者，先統一基準。0.69 dB 只記成對六款中位數表格的擬合誤差，不當成所有喇叭或完整三維聲場的誤差保證。
>
> 其餘沿用原方向，完成核對後進入實作，不為了進一步降低擬合誤差繼續增加模型參數。
>
> 一句話：這次可以往前了。不是要把模型做到完美，而是把「有資料支持的部分」和「暫時採用的假設」分清楚，讓最佳化不要把假設當成真實優勢。

> 容差採 \(2^{-30}\)，明確定義為功率倍率公式解對獨立數值積分的相對誤差，僅用於這項數值一致性檢查，不代表喇叭或房間的仿真精度。
>
> 測試包含預設值與允許參數範圍的邊界，並用典型錯法確認測試確實會失敗。不要把目前測過的結果寫成所有情況都保證通過，或所有公式錯誤都一定抓得到。完成後繼續第一刀，不必再為這個數字另開研究。
>
> 重點就是：這個容差可以用。把測試定義與適用範圍寫清楚，就往前做，不需要再糾結小數點後要守幾位。

老闆更早的方向（原話）：「spinorama 這個可能還先不用接　我們第一階段在觸發低頻的部分　應該就是球體（因為低頻比較沒有方向性）　第二階段要開始判斷反射才開始有對吧」。

**覆核者的建議**（老闆轉貼的外部覆核，不是老闆原話；全文在 #505 留言）：正前方參考固定、晚期能量乘同一模型的功率倍率、T20／T30 不動、朝向固定且同一候選只有一個朝向、上一代模型保留作對照不當預設、平滑模型要能涵蓋代表性方向性範圍。

**主對話的約定**（照上面推的施工細節，不是老闆拍板）：允許的參數範圍、聲源模型必填、同表身分的寫法、上一代相容對照做成非預設種類、施工分四刀。
