# 報表八度帶納入 8000 Hz

## 問題

幾何路細軸已到 8000 Hz 八度帶上緣，但正式報表中心仍停在 4000 Hz。新增一帶會讓鏡像法的
0.5 Hz 帶內密軸多 11314 點，也會讓殘響正式開始評估先前已拍下的 8000 Hz 目標區間，因此要在
知道成本後另行拍板。

## 選項

1. A：報表維持 125～4000 Hz 六帶，8000 Hz 只供音色細軸使用。
2. B：報表加 8000 Hz 成為七帶，殘響目標與同帶密軸一起生效。

## 決定

採 B。

- `GEOMETRIC_REPORT_OCTAVE_CENTERS_HZ`（幾何報表八度帶中心清單）在 4000 Hz 後加入
  8000 Hz；報表與晚期衰減照它產帶。殘響評估讀的是品質登記簿自己那份中心清單，兩份由考卷
  `test_reverberation_cost.py::test_formal_reverberation_interval_is_the_decided_one` 綁成集合相等；
  晚期混響命令列的帶則跟著輸入檔。
- 8000 Hz 殘響 T20（衰減 20 dB 推估的殘響時間）目標為 0.25–0.6 秒：名義值 0.425 秒、
  容許量 0.175 秒。區間內不罰，低於 0.25 秒或高於 0.6 秒才罰。
- 鏡像法帶內密軸仍採 0.5 Hz，新增帶與其餘六帶一視同仁；總點數由 11137 增為 22451，
  因此多 11314 點。
- 1/24 八度細軸仍為 220 點，有限元素路仍為 94 點；兩者都不因新增報表帶改動。
- 上一代答案只有六帶，仍照原答案頻帶比較；新增帶要明說沒有上一代答案，不算比較錯誤。

## 為什麼

老闆已決定報表要涵蓋 8000 Hz。#440 的量測在既有六帶顯示 0.5 Hz 密軸已收斂；加帶之後又對
8000 Hz 帶補量一次（K=3、三個場景）：0.25／1／2／5 Hz 對 0.5 Hz 的差都在 0.001 dB 內，細軸
24 點偏 0.5～1.1 dB——同一結論，不因高頻帶另設較粗規則。殘響的 8000 Hz 目標早已在 #430 拍下，只是等待晚期混響真正產生這一帶；本題補齊該條件。

## 代價

- 鏡像法 K=3（交接階數三階）六帶實測約 1.7 秒、七帶實測 3.4 秒；一份完整報表（參考房、單緒）
  實跑 5 分 13 秒，與六帶那次的 5 分 27 秒差在機器負載的雜訊內——報表時間在晚期混響與有限元素。
- 8000 Hz 帶的上緣 11314 Hz 高於能力表宣告的細軸末點 11166 Hz（軸的最後一個格點），所以殘響
  評估對這一帶的模型驗證狀態是「沒查過」而不是照抄表上的「試驗中」；兩者都算未驗證，只差標籤。
  #347 之前 4000 Hz 帶（5657 對 5583）也是同一形狀。要不要改判法另題。
- 既有上一代答案檔不重錄，所以 8000 Hz 沒有跨代數值比較；新帶仍有產品計算與目標區間考卷。

## 拍板

2026-09-22，老闆在票 #437 對「報表八度帶清單加 8000 Hz 帶」回「好」。
