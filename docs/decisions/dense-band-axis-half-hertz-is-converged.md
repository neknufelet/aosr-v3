# 帶內密軸 0.5 Hz 已收斂，所有報表帶一視同仁

## 問題

原先想縮短鏡像法時間，提出依頻帶放寬密軸間距；但最初的 A／B 判讀把 #302 的證據讀反，
把「細軸在高頻偏掉」誤當成「高頻可以少取樣」。要先量出密軸在哪裡收斂，才能決定省哪一段。

## 選項

1. A：高頻帶用較粗間距，或直接退回每八度 24 點的細軸。
2. B：所有報表帶維持 0.5 Hz，不分帶。
3. C：先量 0.25、0.5、1、2、5 Hz 與細軸，再依量測決定。

## 決定

量完採 B：0.5 Hz 留著，所有報表帶一視同仁，不分帶、不放寬。

- 六個既有報表帶、六個場景，在 K=3 與 K=8（交接階數三階與八階）下，0.25 Hz 對 0.5 Hz
  的最大差為 0.014 dB；1 Hz 最大 0.015 dB。
- 2 Hz 與 5 Hz 最大差都是 0.07 dB，最壞都落在 125 Hz 帶。
- 每八度 24 點的細軸在 4000 Hz 帶偏 1.2～1.3 dB，不能取代密軸的帶內平均。（#302 記的
  +0.74／+0.72 dB 是「補干涉項前後」的差，這裡量的是「24 點對 0.5 Hz」的差，量法不同、方向一致。）
- 密軸六帶 K=3 約 1.7 秒，K=8 約 31 秒；完整報表時間主要花在晚期混響與有限元素，
  不是 K=3 的密軸。
- 音色計分讀細軸逐點資料，殘響計分讀晚期衰減擬合；兩者都不經密軸。

## 為什麼

0.5 Hz 相對 0.25 Hz 的最壞差只有 0.014 dB，已足以視為收斂；再加密沒有相稱收益。反過來，
細軸在 4000 Hz 已偏超過 1 dB，證明不能先假定高頻不需要可靠的帶內平均。老闆原話：
「要省的是超過需要的取樣密度，不是先假定高頻不需要可靠的帶內平均」。
