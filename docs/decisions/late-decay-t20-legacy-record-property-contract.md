# 晚期衰減 T20 上一代答案改為相容紀錄，改由精確常數 Eyring 性質擋合併

## 問題

舊紙判 T20 與上一代算法相同（第一類），以每頻帶相對差 ≤ 2^-20 擋合併。票 #306 老闆回 A 後，晚期混響改用無規入射吸音率、形狀因子守互易，
T20 的衰減曲線跟著變，上一代答案不再是同一算法的答案（參考房 T20 縮短三到四成）。

## 選項

- **A：上一代 T20 降為相容紀錄**：答案與比較器保留、不擋合併，另立獨立性質擋合併。
- **B：維持舊契約**：與 #306 的決定衝突，不可行。

## 決定

採選項 A。

- 上一代 T20 答案（`blueprint/reference_art_decay_{flat,varied,lowabs}.json`）依 `legacy-answers-three-roles.md` 降為第二類：照量、照留、不擋合併。
- T20 擬合算法照舊：同一條晚期混響衰減曲線、−5～−25 dB 加權直線擬合、256 階、擬合無效報錯。
- 擋合併的獨立性質：均勻材料房間，T20 與 T30 各自等於考卷自寫的精確常數 Eyring 公式 `T = 24·ln(10)/c · V / (−S·ln(1−ᾱ_d))`，
  相對差界線 `2^-30`（與晚期混響性質同一常數）。T30 合成衰減性質考卷（`late-decay-t30-property-tolerance-2pow30.md`）照舊。

## 為什麼

- 均勻材料房間的漫射場衰減是單一指數，階數換時間的係數正是 24·ln(10)/c；實測 T20 對精確常數 Eyring 相對差 flat 8.1e-16、lowabs 1.7e-16，T30 為 2.0e-16、3.5e-16。
- 產品 Eyring 常數 0.161 對 24·ln(10)/c（c=343）差 7.07e-4，所以考卷不呼叫產品 Eyring，改用精確常數。

## 代價

- 非均勻材料房間的 T20 沒有獨立真值，只靠同一條衰減曲線的擬合正確性。
- 不再能用上一代答案抓 T20 的小錯。

## 拍板

2026-09-15，老闆在票 #306 回 A（原話「A」）；精確常數 Eyring 性質是助理依量測補定，界線 2^-30 待老闆確認。
