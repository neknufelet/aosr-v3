# 第三階段梯度搜尋的目標與找法：目標從低頻那一路換成產品六類（三路都進梯度）、全牆聯合梯度為主、取規格聯合重調空腔、少量候選確認、換樣板走「候選範圍加預算」含不貼；目標 JAX 版對 Python 版另立尺

這張紙一換一取代 `stage-three-gradient-objective-low-frequency-lane.md`（活紙 60／60 已滿）：舊紙的決定逐條搬過來（第 1～8 條原文不動），加第 9 條「在樣板之間挑」——舊紙第 4 條寫「另問、另紙」的那一題。

## 問題

段序紙 `optimization-stages-room-with-positions-then-layout-then-zoned-materials.md` 表一第③列只寫第三階段「JAX（自動微分計算庫）梯度」，沒寫梯度要往哪個目標走、離散規格（棉板只有 50、100 mm 兩種）跟連續量（空腔 0～150 mm）怎麼一起找、什麼時候停。
2026-10-15 在票 #561 把找法定下來了（老闆回「A」之後接著問，改成梯度為主；定義照老闆轉貼的覆核寫、主對話核過，老闆回「好喔」），當時寫「接進計算時寫進第三階段的決策紙」。替身求值（#949、#952）、可微構造入口（#948）、整條梯度鏈與候選確認迴圈（#962、#964）、命令列與終點（#971、#973、#982）都進了產品。
現行的評分程式（`src/aosr/scoring/stage_one_low_frequency.py`、`stage_one_score.py`）是 numpy 與純 Python 寫的、不能自動微分；要一份 JAX 版，就要定它對原版的尺。
梯度只會沿著能連續變的值走（棉厚、空腔）；「這面貼哪一種構造」（家族與不貼）是挑一個，梯度跨不過去。示範房第一場（2026-10-30）六面固定樣板只調連續量，結果五面全頂到總深度上限、仍輸原牆基準；系統要有能力把一面換成別的家族、或整面不貼。

## 選項

- **A**：第一輪的梯度目標只用有限元素那一路的第一階段低頻分數（兩分項與合分照登記簿 `[[stage_one]]`），大峰不進梯度目標；找法照 10-15 的定義；目標 JAX 版對 Python 版另立尺。
- **B**：等六類評分全部可微（#562）再開梯度，第一輪就用產品六類總分。
- **C**：第一輪不用梯度，每面逐一比 14 種構造（2026-10-28 的第一版計畫；跟已拍定的方法牴觸，老闆同日指出「仔細去找一下我們之前的歷程」後作廢）。
- 換樣板（2026-10-28 問）：**限制範圍的 A**——每面只准指定家族加不貼、梯度只調連續參數、換樣板用候選確認法；**限制預算的 B**——所有合法樣板加不貼都可參與、每輪先快速評分、只重調少數候選、輪數與時間限住。

## 決定

目標與找法採 A；換樣板採 B 的候選範圍加預算。

1. **目標（第一輪）**：每支喇叭兩分項——主位曲線（dB 對 log2 f）扣自己的加權最小平方直線後的加權均方根；周圍六點各自對主位逐頻 dB 差的加權均方根、六點等權平均；頻率權重是範圍內每八度等權、切到計分範圍上下界；逐聲道等權平均；合分＝Σ 權重 × 值／較差參考。算式、範圍、權重、較差參考全部照 `src/aosr/config/data/quality_targets.toml` 的 `[[stage_one]]` 讀，JAX 版不寫任何數字。能量＝替身聲壓的 |p|²，跟 `fem_batch` 同一個定義。
2. **大峰以平滑代理進梯度目標（2026-10-30 老闆拍 B，初始試驗）**：峰谷偵測（`timbre._features`）不可微，梯度目標改成「第 1 條的合分 ＋ w × P ÷ ref」：P 是主位扣自己直線後的殘差在計分範圍內部點（去掉兩端點，偵測器也不算端點）、左右兩支一起取的軟最大值 T·log Σ exp(r/T)，夾在內部最大殘差與它＋T·ln N 之間（N＝內部點數×喇叭數）；內部最大殘差不一定是峰，殘差往計分範圍邊緣一路爬時它落在倒數第二點、偵測器的局部峰可低很多（實例 #999），邊緣隆起照罰（見下一點）；w＝0.25、T＝0.25 dB、ref＝1.0（跟兩分項同一把尺）住登記簿 `[[stage_one]]` 段的 `stage_three_gradient.*` 三格、全是 baseline、程式不寫數字。只進梯度目標：第一階段篩選分數與第二階段總分一位不動、兩邊設定指紋不含這三格。
   - 邊緣隆起照罰、定義不改（2026-11-03 定，見文末原話）：一路往邊緣爬可能是範圍外一個峰的山腳，所以這一項叫「內部最大殘差」，不叫「大峰」；最後一場終點代理比真大峰只高 0.22 dB，兩種定義結果幾乎相同。
   - 誰能判它錯：終點完整模型同時印舊合分（兩分項）、新合分、代理與真大峰（現行偵測器 `big_peaks`）；代理降而真大峰升就是代理錯；示範房第三場的表舊新分數並列、名次各自列，名次只因加權改變不算聲學改善。鏡像法與晚期混響那兩路、六類總分仍等 #562；大峰進不進產品總分是 #339 第 8 題，這裡不決定。
3. **找法**（2026-10-15 定義，逐條照搬）：以全牆聯合梯度最佳化為主；連續厚度要轉成滿足施工限制的合法規格、同時聯合重調空腔，不准各牆各自取最近、取完就交付，總深度、總價、重量這類限制要在取規格時一起滿足；在可行解重算梯度，用「梯度 × 實際規格跳距（帶方向）」估每面換規格的變化、提出少量候選（第一版預設 3 個，沒有理論保證）；入選候選從目前解出發、所有牆的空腔做有限步數的梯度重調、再用整房目標比，基準方案也用同樣步數重調，改善超過門檻才接受；停止條件是在設定的候選數與計算預算內沒有找到超過改善門檻的可行替換；候選數、輪數、總計算量都有上限，停下時記下原因；最終方案與幾個接近的候選用完整模型重算同一套評分再交付。
4. **不宣稱全域最佳**：只試前幾名，不能說「換任何一面都不會更好」；就算每面都試過也只排除了單牆替換。連續厚度放寬只用在同一個有物理意義的材料模型（同系列、不同厚度）；不同材料或不同層疊不能把材料編號當厚度微分；在樣板之間挑的做法見第 9 條。
5. **尺**：目標 JAX 版（`src/aosr/scoring/stage_one_objective_jax.py`）對現行 Python 評分程式（`evaluate_stage_one_low_frequency`＋`score_stage_one`）逐喇叭兩分項與合分的相對差，契約 `stage_one_objective_jax_vs_python` 住 `blueprint/precision_contracts.toml`，值 2^-36（相對差，暫定：2026-10-28 本機最大 5.75e-15、純直線主項以 1 dB 為尺度最大 1.15e-14，留約千倍給換機器）；梯度對中央差分的尺住考卷、不是產品契約；單精度只量不登記，顯卡單精度另立尺、等接進計算用顯卡實量再登記。
6. **替身方程式的停止殘差**（0.01）要不要收緊，等接進計算、真房間量過再定（`fem-reduced-model-jax-evaluation-for-stage-three.md` 代價段）。
7. **住址**：整條可微鏈、投影下降、取規格與空腔重調、步驟帳本住 `src/aosr/gradient/`（層次表跟 search 同一組、可以拿 physics 與 scoring）。search 照 #585 立的考卷不直接拿物理（搜尋程序把有限元素交給子行程），而梯度鏈要在行程內做自動微分，所以另立一個資料夾、不放寬那題（2026-10-28，庚一全套考卷抓到才定）。
8. **「不貼」＝保留方案原本的牆（2026-10-29，#561 辛三接線）**：preset 寫 none 的面不是剛性，從替身鏈、終點完整模型重算到匯出方案檔都用方案場景那一面原本的材料（固定阻抗或構造）同一支阻抗函式算；終點另算「方案原本六面」的完整模型基準，第一張表的改前改後都用完整模型同一把尺。兩個都沒有（沒樣板也沒原牆）才是剛性，只剩合成考卷在用。
9. **在樣板之間挑（庚三，2026-10-28 老闆拍 B 的候選範圍加預算；2026-10-30 加保留原牆）**：
   - 候選單位是**家族**（設定檔 `[[family]]`，同層疊只差初始空腔的預設視為同一家族的不同起點）加「不貼」（第 8 條的保留原牆）；起點是第 3 條的候選確認迴圈交出的整房方案，不從頭來。
   - 每輪：把每一面各換成別的家族（用家族登記的換樣板構造與合法初值）或不貼，各用替身目標**快速評分一次**；值最好的最多 N 個進空腔重調（步數同第 3 條），基準（目前方案）用同樣步數重調；改善超過門檻（同第 3 條的門檻）才接受、一次只接受一個替換，再以新整房方案開下一輪。
   - 輪數、這一段的求值次數、這一段的總時間（帳本記的各輪秒數加總，不看牆鐘，接續才重現得出同一個決定）都有上限；停下時原因照實寫：「在本輪已確認的單牆候選與計算預算內，未找到超過改善門檻的方案」，不寫「排除了單牆換樣板」。
   - 換樣板段有自己的帳本（每一列自帶六面配置與變數名，θ 的版面換了也讀得回來）；第 3 條那本帳不動。終點（完整模型重算與原牆基準）用最後的配置。報告要分清楚哪些候選只快速評分、哪些重調過、哪些沒有可重調的變數、完整模型只確認了終點。
   - N、輪數、求值與總時間上限、各家族的換樣板構造與初值都住設定檔 `material_gradient.toml`，工程暫定、調整走 PR。
   - 安裝方式（#990，2026-11-01 老闆拍「新增安裝方式、剛背照留」）：每次搜尋一個值（剛背／貼在原牆上），換樣板沿用、不列舉；貼在原牆上時樣板背後接方案那一面原本的材料，進資料夾名、兩本帳的表頭與結果檔（v5）；剛背的資料夾名、帳本表頭與結果檔（v4）跟加這一格之前逐位相同。
   - 每區准用清單（#1082 段 2-3b，2026-11-11）：交給搜尋的面或面片可以給一份准用清單（家族、固定材料 `fixed:<代號>`、不貼），換樣板只換到清單裡的，起點也要在清單裡（限制是硬的）；沒給清單的面照舊換全部家族加不貼，固定材料只從清單進來（不然內建十五筆會灌滿每一面的候選）。固定材料整塊換上、沒有變數，搜尋頻點與終點用同一支阻抗函式、同一份材料（實測表表外照之七紙用底構造補值）。
   - 開跑前，清單裡每個固定材料各做一組替身留出驗證：放到准用它的每一片、整條頻率軸完整解對替身，尺跟准用閘門同兩把；沒過就拒收、照實寫數字，不放寬、不偷偷補訓練（光牆 ≥75ρc 以前就是收據過了、換上去沒過，#990）。有深度上限的面這一段不准列固定材料（固定材料的厚度量不出來，2-4 再處理）。清單與固定材料摘要進資料夾名、`project.json` 與換樣板帳本表頭（版本不升）；沒有清單逐位照舊。

10. **第三階段專用計分範圍（#1032，2026-11-07）**：材料梯度搜尋與終點驗算的低頻計分改為 30～300 Hz，讀品質登記簿第一階段段落的新格 `stage_three_gradient.scored_range_hz`；第一階段照舊讀 `stage_one_low_frequency.scored_range_hz`，第二階段也不動。30 Hz 以下不計分：終點與原牆各加註從第一階段下界到第三階段下界（不含）的最強峰中心與對自己擬線的峰高、座位平均能量最高點與 dB，另列原牆減終點的差；峰仍用完整第一階段範圍擬線後篩選，不另定演算法。舊目標指紋資料夾要重新開始搜尋。
11. **梯度目標換成產品六類（#562，2026-11-08 老闆拍 A）**：取代第 1 條作為第三階段的梯度目標；第 1、2 條的算式照留，成為低頻頻響類的類內項。
   - 目標＝產品排名代價：六類各自照登記簿 `src/aosr/config/data/quality_targets.toml` 的代價形狀、類內權重、範圍與較差參考，類間權重讀 `ranking.category_weights`（低頻頻響 0.25、其他 1.0）；JAX 版不寫任何數字。低頻頻響類照第 10 條用 30～300 Hz，其他類照各自登記的範圍；替身頻率軸照舊從方案的低頻軸起算。
   - 三路都在梯度裡：有限元素替身（300 Hz 以下）、鏡像法（反射三階）、晚期混響（每面 6×6 格），照正式三路報表的交接 max(f_s, 150)～300 Hz 平滑接合；材料到幾何路的斜入射阻抗、無規入射吸音、房間散射 s(f)、逐階晚期能量與尾巴、殘響 T20 都在 JAX 內算。殘響、音色、早期反射、聆聽區、左右匹配五類跟低頻一起當最佳化因子，不先用簡化公式估、不留到終點才算。
   - 交接權重的梯度擋掉（stop_gradient）：權重值照算，梯度不穿過權重，只穿過各路自己的能量。「材料改了所以更信哪一路」不是物理梯度，讓梯度推它等於讓最佳化挑模型；梯度因此不是完整導數，線搜尋照舊用真值守下降。f_s ≥ 上限（FEM_GEOMETRIC_CROSSOVER_CAP_HZ）時照 numpy 硬切：頻率 ≤ 上限全有限元素、> 上限全幾何。capped_by_upper_limit（到達交接上限）只供報告，不使有效輸入的能量回 NaN；權重仍擋梯度（2026-11-08 主對話修正：原寫「回 NaN」，109 號房原牆 f_s 約 302 Hz，起點整段不可估）。
   - 不可微或會失敗的地方：編譯過的函式裡不丟錯，改成旗標、該項回 NaN，不默默換成簡化公式；T20 到不了衰減下緣、斜率非負、吸音到 1 都屬這類。殘響代價只平均估得出 T20 的頻帶，分母會隨旗標跳，這是離散行為，報告要印每類可估帶數。早期反射四區最強路徑第一版直接取最大值（產品定義，次梯度），線搜尋反覆退步才另開題改軟最大值。峰谷清單、顫動警戒、左右反射差、對目標偏差照登記簿只比較或警示，不進代價。
   - 大峰代理照第 2 條留著，放在低頻頻響類裡面、跟兩分項一起乘類權重 0.25，類內 1：1：0.25 的比例不變（第三場與最後一場驗的就是這個比例；獨立成一項會讓代理對兩分項變四倍強、沒跑過）。代理不在產品六類總分裡，所以梯度目標仍不等於產品總分，終點兩個都印。
   - 誰推得動：範圍型與門檻型在容許帶內代價與梯度都是 0，只當護欄（照登記簿現行形狀，不改計分定義）；從普通起點連續推動的是音色起伏、低頻兩分項與大峰代理。報告逐類印「這一場有沒有推過」。

## 為什麼

- 老闆 10-15 原話「之前就是因為高維 才會堅持繼續用梯度來做」「如果因為梯度不能用代理模型也沒關係 但梯度應該還是最理想的」：規格一種一種比在六面兩種時是 64 組、二三十面就炸掉；10-15 定義的說法是「設計參數增加，不必讓梯度計算次數等比例增加」，實際時間與記憶體仍取決於房間計算與微分實作。
- 代理試驗（工作區 `561-discrete-gradient/many-walls/`，24 區簡化房）：只取整重調空腔 15 題 5 題在最佳已知 0.1 ms 內、最大差 2.08 ms；加「梯度挑三面確認」14 題在 0.1 ms 內、最大差 1.33 ms，計算次數中位數 225→297。只看總吸音量，不代表真房間的離散化損失也小。
- 第一輪先用低頻那一路：替身求值已在產品；每次求值（值＋梯度）示範房 188 點軸、秩 1009 時 4.6 秒、秩 1572 時 13.8 秒（2026-10-28 中央處理器雙精度實量，BLAS 釘單緒、跟產品計算子行程同一組環境；BLAS 多緒時同一段會慢幾十倍，計時一律先釘緒；#610 的 0.74 秒是實驗室房、94 點、顯卡單精度的數字，產品環境目前是純中央處理器版），六類總分要等鏡像法與晚期混響接進同一迴圈；先出一張「低頻這一路貼什麼最好」的表，比等全部接完再出表快。
- 目標要跟現行評分同一套算式：第一階段與第二階段低頻頻響類（0.25 × 這個合分）都用它，梯度找出來的方案才跟搜尋、比較頁看到的分數是同一把尺；另寫一套目標就是第二個家。2026-10-30 起梯度目標多一項代理，不再等於第一、二階段的分數；舊合分照算照列，代理是加在同一把尺上的試驗項，不另立第二套合分定義。
- 換樣板走 B 不走 A：老闆 2026-10-28 的覆核算過，擴大範圍多出的只是每輪一次快速評分（六面 × 可換數，示範房替身一次約 13 秒、18 個約 4 分鐘），重調只做少數候選，「慢三四倍」推不出來；而範圍收窄的 A 連「整面不貼」都要人先指定。示範房第一場證明固定樣板只調連續量會把五面都推到深度上限、仍輸原牆（第一張表，工作區 `561-demo-search/`）：系統要能自己選「不貼」，才回答得了「貼什麼最好」裡的「不貼最好」。

- 換成產品六類（第 11 條）：低頻那一路的表出來以後，109 號房終點對原牆的六類並列（2026-11-08，分區方案第一次進正式三路報表）顯示殘響與早期反射順帶變好、音色變差——梯度沒看音色。六類同一套代價進梯度，找出來的方案才跟比較頁的總分是同一把尺；交接權重擋梯度，讓梯度只走物理、不挑模型；真正失效的數值仍用旗標與 NaN。109 原牆 f_s 約 302 Hz，若到達上限就回 NaN，連起點都沒有值，終點三數並列也做不了；本次改為正式 numpy 報表原有的硬切與上限旗標，兩條路保持一致。

## 代價

- 大峰只是代理：高估內部最大殘差最多 T·ln N（不是高估真大峰，見 #999）（示範房 188 點軸兩支約 372 個內部點、T＝0.25 dB 時約 1.5 dB），T 越小越貼近真值、目標越接近不平滑、線搜尋可能更常退步長；權重 0.25 對第二場那種 6.09 dB 的變化等於 1.52 分、足以逆轉名次，所以名次改變不等於聲學改善，兩套分數並列才算數；第二場資料夾的評分常數指紋不同、不能接續，第三場要開新資料夾從頭跑；代理只看主位、六座位的峰不在裡面；終點「替身對完整模型的差與差的上界」仍只算舊合分，新合分只並列不推上界。
- 第一輪的表只回答低頻那一路，六類總分的表要等 #562；兩張表可能不同，到時並列。
- 候選數 3、改善門檻、步數、預算都是工程暫定，數字住設定檔、要調走 PR；沒有理論保證。往下走步數上限 2026-11-11 起 60（原 30，#1073）；開跑時可用 `start --max-steps N` 另指定一跑的上限，記進那個搜尋資料夾、接續與報告照記的套回；網頁還開不了第三階段，網頁上的選項等網頁能開跑再做。設定指紋含這一格，改值前沒跑完的資料夾不能接續。
- 實際時間與記憶體取決於房間計算與微分實作（反向微分要存中間結果）；多切材料區與換成不規則房是兩件不同的事，不規則房今天算不了（#465）。
- 均方根不高於 C·ε·max|levels| 的，值與梯度都當 0（C＝64、ε 是輸入精度的最小刻度、max|levels| 是該喇叭所有座位與範圍內頻點的 dB 絕對值最大值、下限 1 dB；雙精度在 80 dB 約 1e-12 dB、單精度約 6e-4 dB）；地板是 dB 絕對量、不從契約那把相對尺推、也不能拿來跟它比大小（單精度 80 dB 時地板 6.1e-4 dB）；近零的非零小量本來就不保證守相對尺——分別取對數再相減的條件問題，80 dB、座位差 1e-3 dB 時 JAX 對 Python 相對差 1.68e-11、略超 2^-36，修前修後一樣、不是地板造成；單精度地板會吃掉一部分低於 1e-3 dB 的真實座位差（均方根不高於地板者），對搜尋終點的影響等接單精度搜尋時再驗；原因是編譯後捨入殘差除以近零均方根會放大成 O(1) 假梯度（2026-10-28 外部審查指出：座位曲線完全相同時編譯後對共同增益的梯度 −4.489，應為 0）。
- 目標 JAX 版對 Python 版的尺只證明同一套算式在兩種寫法下一致，不證明分數本身對聽感對；「誰能判低音分數錯」照段序紙第 ② 塊的拍板，不在這張紙。

- 帳本標頭（v3，2026-10-29）綁替身身分、設計清單、搜尋設定與評分常數的指紋，接續前比對、不同就拒收；呼叫端另注入的空氣常數與多孔材範圍不在標頭內，靠物理身分的資料檔雜湊守——沿用舊替身、另注入新常數時守不到（外部審查另記）。編譯快取改掛在目標函式上，目標被丟掉時一起回收（原本弱鍵字典的值抓著鍵、永不釋放）。
