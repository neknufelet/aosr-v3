# 低頻時間表現（模態拖尾）的量法：主方法複數特徵頻率、局部細掃交叉驗證；先量成本

## 問題

品質架構（`quality-evaluation-seven-categories-three-layers.md`）第③類「低頻時間表現」是丁類缺口：有限元素今天只解固定頻率的穩態壓力（`src/aosr/physics/fem_helmholtz.py`），沒有衰減。
上一代把「低頻拖尾」做成從頻響找峰再罰，而且它的門檻曲線抄自文獻估讀。要回答的不是「低頻曲線平不平」，是三件：房間有哪些低頻模態、每個拖多久、在目前喇叭與座位下各有多重要。
`#307` 指出 1/24 八度細軸可能取不到模態峰頂——越拖越久的模態越窄、越容易漏；模態靠得近時半功率頻寬也會被鄰近模態污染。

## 選項

1. 從現有 1/24 八度頻響找峰、量半功率頻寬反推衰減。
2. 有限元素直接求複數特徵頻率（阻尼模態）當正式來源；在每個模態附近做局部高解析細掃與半功率頻寬當獨立交叉驗證；再由模態形狀或局部細掃判該模態對指定喇叭與接收點多重要。
3. 等有脈衝響應（時間域）再做。

## 決定

採選項 2。老闆的原話逐字如下，其餘是助理對照 repo 補的落地細節。

> 主方法採 complex eigenfrequency；局部高解析 frequency sweep / half-power 作獨立交叉驗證。評估器以一般 FEM mesh 為輸入，不假設矩形幾何。V1 只支援 frequency-independent impedance。V1.5 的逐次阻抗更新僅為 experimental proxy，需通過收斂與獨立對照才可升級。Frequency-dependent impedance 的正式 nonlinear eigenvalue 解法列為 V2。第一個實作任務先量正式網格下的時間與記憶體成本；成本決定運行策略，不推翻方法選擇。門檻與代價函數等量法驗證後另拍。

名詞：complex eigenfrequency＝複數特徵頻率（實部是模態頻率、虛部帶衰減）；frequency sweep＝逐頻細掃；half-power＝半功率頻寬（峰兩側掉 3 dB 的寬度）；FEM mesh＝有限元素網格；frequency-independent／dependent impedance＝頻率無關／逐頻阻抗；experimental proxy＝試驗性的代理量；nonlinear eigenvalue＝非線性特徵值問題（阻抗隨頻率變、而頻率正是要解的未知數）。

1. **輸出是一張模態表，不是分數**：每個模態一列——頻率、衰減（T60 或明確指定的衰減量）、Q、原始複數特徵值（供追查）、對指定喇叭與接收點的重要性、喇叭與接收點代號、可信度（validated／experimental／unavailable）、方法、不可估原因。模態形狀保存，不進一般排名表。
2. **加阻抗邊界後是二次特徵值問題**（`(K + jω·C − ω²·M)p = 0`，ω 同時出現一次方與平方），要線性化成兩倍大的系統再用複數移位反演求解；分解照 `fem-numerical-tools-scikit-fem-p2-pydiso.md` 只用 pydiso、出錯報錯不換解法。這是新零件，今天沒有。
3. **衰減量與複數慣例不先硬寫**：虛部正負號、Q 與 T60 的換算，由第一個含阻尼的解析基準鎖死。
4. **重要性先從特徵向量算模態參與**（模態形狀在喇叭位置的值 × 在接收點的值 ÷ 模態範數），多喇叭多接收點不用重解、直接接 #349 的接收點清單與 #350 的聲道組；局部細掃的突出程度作交叉驗證，不當唯一來源。
5. **V1 是方法驗證，不是可用於型錄候選的評估**：材料層的吸音率本來就逐頻，V1 頻率無關阻抗評不了真實候選。V1.5「每個模態在猜的頻率取阻抗、解、更新頻率、再取」是待驗近似，不准偷偷做成「取一個頻率的阻抗算整段」。
6. **漏模態自檢**：找到的模態數對剛性牆模態數（有解析式）與 Weyl 估計；強吸音造成的過阻尼或併掉另外標記，不算漏。
7. **驗證三層**：①矩形——先剛性牆對解析模態（`src/aosr/physics/fem_rigid.py` 的解析解補成特徵值形式，驗頻率、模態形狀、網格收斂），再每軸牆對同一實阻抗對**半解析阻尼真值**（分離變數、每軸一條超越方程、三軸靠總波數耦合，三複數未知數聯立延拓求根）驗複數特徵頻率、Q、T60；②孤立模態——特徵頻率法對超密局部細掃＋半功率頻寬，只用孤立模態，靠近的模態不當真值；③非矩形——簡單梯形房對獨立求解器（沿 `fem-contract-fenics-frozen-answers.md` 那條凍結參考線），同幾何、同網格目標、同密度與聲速、同阻抗。
8. **跟 #348 並列**：統計模型的 63／125 Hz 帶 T20 已標「未驗證代表低頻模態衰減」；本科落地後那幾帶把統計 T20 與帶內模態 T60 範圍並排印。
9. **感知門檻只當參考目標**：保存一條隨頻率變、來源明確的參考曲線（文獻範圍 32～250 Hz），範圍外不外推成門檻；第二層代價的形狀（衰減超出量 × 重要性之類）現在不拍成契約。
10. **開工順序**：0 先量成本 → 1 慣例與解析基準 → 2 剛性矩形 → 3 阻抗矩形對半解析真值 → 4 模態參與與孤立模態交叉驗 → 5 漏模態自檢與過阻尼標記 → 6 梯形房對獨立求解器 → 7 升 validated 才談門檻與代價；V1.5 另開研究票。票 #352。

## 第 1 步鎖定的慣例

慣例只有一份：`src/aosr/physics/modal_convention.py`。時間採 e^{+jωt}，
p(t) ∝ e^{j·Re(ω)·t} e^{−Im(ω)·t}，Im ω > 0 代表衰減。
ω 的單位是 rad/s；頻率 f = Re ω/(2π)，單位 Hz。
T60 = 3 ln 10/Im ω，單位 s，是壓力包絡下降到 10^{-3}、能量下降到 10^{-6}（60 dB）的時間。
Q = Re ω/(2 Im ω)，無量綱，是振盪角頻率與兩倍包絡衰減率之比；無阻尼共振的 Q、T60 都為無限。

特徵值變數採 λ = k = ω/c（rad/m），回報再換成 ω = ck。
第 0 步用 λ = ω、質量項 M/c² 時，分解擾動約 32,714 個主元，線性求解相對誤差 0.23；
換 λ = k 後正式量測的擾動主元為零，試跑的線性求解相對誤差約 10^{-14}。
這是數值尺度的證據，不是半解析與有限元素的精度契約；原始出處是第 0 步報告第 1 節與 probe_scaling.json（外部量測附件）。

三種解由 ModalKind（解的種類列舉）標示：Re ω > 0 為會振盪的共振；
Re ω = 0、Im ω > 0 為不振盪衰減；ω = 0 為靜態解。只有共振進模態表。
不振盪衰減有 T60，依上述公式的算術 Q = 0，但不是房間共振；靜態解的 Q、T60 都未定義。
多小算零由呼叫端依整個頻譜的尺度與殘差給（絕對值，rad/s；有限元素的靜態根與無阻尼模態帶 1e-12 等級雜訊，數值由下一步定）；
不給時只容許浮點舍入，適用零支實部精確為零的半解析真值。負頻率支或增長支明確拒絕，不能冒充衰減共振。
ω = 0 時阻抗項 jkCt 消失，純 Neumann（零外法向導數）的常數壓力使 K 奇異，因此任何阻抗都保留靜態根。
它與從剛性零模態分岔的非零衰減支分開記；後者的來源由延拓驗證，不由頻率排序猜測。

邊界由 jωρv = −∇p、向外速度 v_n = p/Z 推得 ∂p/∂n + jkβp = 0，β = ρc/Z。
分部積分給 K + jkCt − k²M，與 `src/aosr/physics/fem_helmholtz.py` 同號。
`src/aosr/physics/modal_rectangle_truth.py` 的每軸方程使用總 k，與 k² = kx² + ky² + kz² 同時求解。
β 從零逐小步增至目標；整步與兩個半步根不一致、殘差不收斂或根移動過大便折半，容易收斂才加大步長。
零指標用消去靜態因子的聯立方程追蹤非零支，仍由牛頓法求得結果；靜態根獨立保存。
頻率排序交叉不等於模態指標交換；同奇偶形狀且軸波數平方相同才標併根，不按頻率近接去重。
併根的每一條都不進模態表、留在帳上待查：兩條會振盪的起點剛好併在目標點不是常態，多半是某條跳了根，不挑一條留下。
奇異併根附近不能穿越時標未解，保留最後成功點；有限起點頻率枚舉不宣稱任意重阻尼下全譜完備。

獨立考卷在 `tests/engine/test_modal_truth.py`：剛性解析式、原始六面邊界、一維管閉式、能量微擾斜率、步長減半與直接跳根反例、手算換算與分類。
參考房用 `blueprint/fem_fenics_problem.json` 自己的尺寸、聲速與密度；證據由 `blueprint/modal_rectangle_probe.py` 現算，不把數量寫成考卷答案。
本步不接搜尋、候選評估或排名，不新增精度契約；有限元素特徵值仍留下一步。

## 為什麼

- 從頻響找峰是「先取樣、再猜山頂」：#307 的軸解析度問題會直接進拖尾的數字。直接求阻尼模態，#307 就只剩音色那一科要管。
- 小房間低頻由個別模態主導，整房一個殘響時間代表不了它；#348 已經把那幾帶標成統計估計。
- 評估器吃網格不吃長寬高，是為了斜牆、斜天花、多邊形房來的時候不用重寫這一科；矩形只是驗證工具。
- 矩形加均勻實阻抗有半解析真值，含阻尼的驗證比只驗剛性牆多守住最關鍵的那一格——衰減；也是鎖複數慣例最便宜的地方。
- 模態參與從特徵向量算不用再解一次，多接收點與多聲道的資料結構（#349、#350）才接得上；局部細掃留作交叉驗證是因為它便宜且獨立。
- 先量成本再定運行策略：參考房到 300 Hz 約兩百個模態、七萬兩千多個未知數（P2；節點約九千七百。原寫「八千多」是節點數的量級，2026-09-19 票 #352 第 0 步實量後更正），線性化後翻倍，複數分解的時間與記憶體沒量過；不量就排程是猜。

## 代價

- 新零件（二次特徵值的線性化與複數移位反演）沒有現成程式，成本未量；量出來太貴只能改運行策略（頻率上限、模態數、只算主位相關的模態），不推翻方法。
- V1 評不了型錄候選：材料最佳化真正用得上要等 V1.5 過驗或 V2；這段期間第③類在排名裡是「未評估」，不是「沒問題」。
- 半解析阻尼真值只蓋每軸牆對同一實阻抗；同一軸兩面不同或非矩形時，仍須第三層的獨立求解器。
- 靠得近的模態沒有可靠的半功率真值，交叉驗證只能挑孤立模態；重阻尼時模態併掉或過阻尼，標記得出來但沒有真值。
- 非矩形的方法支援不等於產品入口支援：幾何、材料標籤、網格產生今天只有鞋盒，非矩形入口另排。
- 本紙只拍方法與邊界，零數字：門檻、參考曲線的取值、代價形狀全部另拍。
