# 有限元素正式路徑由 FEniCS 離線認證並以凍結答案擋合併

## 問題

票 #255 的選項 B 用上一代規則網格加 P1（一次元素）作為相容設定，守住原契約①：flat（有吸音的平坦案例）逐頻點對上一代的複數壓力相對差不超過 2^-12。

這條相容路只證明規則網格加 P1，沒有直接守正式路徑 gmsh（產生網格的工具）加 P2（二次元素）的吸音項。老闆因此提議，用 FEniCS（外部有限元素程式）在正式網格上獨立算一次，讓外部答案直接檢查正式路徑。

## 選項

- **A：離線認證，凍結 FEniCS（外部有限元素程式）答案。**
  1. 正式路徑由②剛性九點對解析解不超過 2^-10，以及④ v3 對凍結的外部答案每點相對差不超過 2^-30 擋合併；網格作為題目一起凍結。
  2. 期望值用 FEniCS 算的壓力，不用 v3 自己的輸出。版本庫只放題目與答案，外部程式、Docker（容器工具）映像與產生腳本留在本機。
  3. 原網格對 0.5 倍網格的自我收斂只在本機認證時量一次並留下證據，不進雲端；票 #257 併入本紙。
  4. 原契約①降成相容紀錄，不擋合併，也不搬上一代規則網格產生器；票 #255 的決策紙由本紙取代。
  5. 答案紅了不准只換數字重錄；答案檔出身與重錄限制另由票 #259 的候選卡處理。
- **B：維持票 #255 的選項 B。** 保留上一代規則網格加 P1（一次元素）的相容設定守原契約①，正式路徑繼續只由②與自我收斂把關。

## 決定

採選項 A，取代 `docs/archive/fem-contract-compat-regular-mesh-plus-p2-path.md`，並吸收票 #257。

1. 正式路徑保留兩道擋合併檢查。②不變：剛性牆在 20 Hz 以下的九個離共振點對解析模態解，逐點相對差不超過 2^-10。新增④：v3 對凍結的 FEniCS（外部有限元素程式）答案，每點複數壓力相對差不超過 2^-30。
2. 版本庫只放題目與答案。題目是網格與物理條件，答案是 FEniCS 算出的壓力。FEniCS 程式、Docker（容器工具）映像與產生腳本都不進版本庫，留在本機工作區；映像以 digest（內容識別值）鎖定並在本機備份。雲端和其他考卷一樣只拿 v3 輸出對答案。
3. 凍結答案一律採 FEniCS 的輸出，不採 v3 自己的輸出。期望值來自外部程式，不讓被檢查的實作自己證明自己。
4. 自我收斂在本機產生答案時量一次：原網格 P2（二次元素）對 0.5 倍網格 P2，結果寫進證據，不進雲端。票 #257 的問題到此併入本紙。
5. 原契約①，也就是 flat（有吸音的平坦案例）對上一代逐點相對差不超過 2^-12，在正式路徑降為 `docs/decisions/legacy-answers-three-roles.md` 的第二類相容紀錄：照量、照記、不擋合併；不搬上一代規則網格產生器。②的案例、門檻與擋合併地位不變。
6. 三種情況要回本機重算答案：網格換了；物理多了新房型、新牆面類型或分格材料；套件升級後，v3 對凍結答案的差距超過 2^-30，而且查不出是 v3 的錯。
7. 答案檔出身與「紅了不准只換數字重錄」目前沒有機器守。候選卡在票 #259；等第一份 FEniCS 答案檔進 `blueprint/` 時再立卡。

## 為什麼

- FEniCS（外部有限元素程式）的剛性九點對解析解，最多用掉 2^-10 門檻的 1.29%。監督比對同一張網格與 P2（二次元素）的結果：flat（有吸音的平坦案例）每點最大相對差 2.0e-14，lowabs（較低吸音案例）為 5.0e-14；兩者較大的 1/3 八度帶能量差是 2.6e-13 dB，出現在 lowabs。
- 兩套程式的組裝、積分與解法都不同。吸音項的正負號與音源強度也各自從物理式推導；寫 FEniCS 的一方沒有讀過 v3、上一代或實驗室程式，比對由監督另做，因此不是從被檢查的輸出抄期望值。
- 本次量測用的是實驗室那張網格。第七段 v3 自己的網格完成後，要用那張正式題目重算一份 FEniCS 答案，不能把本次數字直接當成新網格的答案。
- 本機自我收斂量到，原網格對 0.5 倍網格的最大帶差在 flat 是 0.060 dB、lowabs 是 0.040 dB。這是產生答案時留下的網格證據，不必把較細網格求解搬進雲端。

## 代價

- FEniCS（外部有限元素程式）要靠 Docker（容器工具），不走 uv（專案環境工具），因此進不了現有雲端；重算答案只能在本機做。
- 雲端驗不了「答案真的是 FEniCS 算的」。這跟上一代答案檔靠自報出身是同一個洞；答案檔出身與禁止只換數字重錄要等票 #259 的卡來守。
- 「對一次」只蓋到認證過的房型、材料與頻點。新房型、新牆面類型、分格材料或其他新物理功能，都要各自重新認證。
- 原契約①從擋合併降成只留證據的相容紀錄，正式路徑不再由上一代 flat（有吸音的平坦案例）答案擋合併。
