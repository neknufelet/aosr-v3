# 同一個候選裡，同一個代號只能指到同一個座標

## 問題

候選包（一個候選方案的全部分類評估）在票 #408 之後只核對候選代號與場景指紋（`docs/decisions/candidate-envelope-checks-scene-not-report.md`）。場景指紋刻意不含聲源與接收點座標——左右聲道是兩份報表、聲源位置本來就不同。副作用是同一個候選**裡面**各類之間的擺位一致性沒有任何東西在守：音色那一類來自 A 喇叭、聆聽區來自 B 喇叭，裝得進同一個候選；同一間房、同一組材料、喇叭擺位不同的兩批結果也混得進去。排名出來的分數可能是兩種擺法拼出來的，沒有人會發現（票 #417）。

## 選項

1. 立契約：每一類帶自己用到的代號對座標，裝包時互相核對，對不上就拒收。
2. 先放著，靠呼叫端自己別裝錯。

## 決定

選項 1。

- **每一類評估多一格「擺位」**（`src/aosr/scoring/placement.py`）：這一類實際用到的「喇叭代號→聲源座標」與「接收點代號→接收點座標」兩張表，單位公尺；同一張表裡代號不可重複。這一格必填、沒有預設值。可估的評估兩張表都至少一筆；不可估的評估准帶空表。
- **座標只從物理報表拿。** 音色與殘響的正式轉接器從三路接合報表「場景」一節的聲源座標與接收點座標拿，不開讓呼叫端覆寫座標的參數。喇叭代號與接收點代號照舊由呼叫端給——代號仍然只是一張貼紙，這一張守的是「同一張貼紙不准貼在兩個地方」。
- **彙總類（聆聽區、聲道匹配）**：擺位從它疊的每一份音色評估收集，放的是每一份音色評估自己報的代號，不是彙總類出身上那種總括代號（這些代號跟接收點集合、聲道組上的代號對不對得上，由原本那幾條身分核對守，擺位這一格不另外對）。批內同一個代號出現兩個不同座標，整類不可彙總，原因碼指名是擺位；只有這種衝突的結果帶空的擺位——不挑其中一筆冒充。因為別的原因不可估、而擺位本身沒衝突的，照樣帶著合併好的擺位。輸入換順序，輸出逐格相同：擺位照代號排，原因碼與旗標照列舉宣告的順序排（後面這一條是這一票順手修的，原本會跟著輸入順序變）。
- **反射與回音這一類不是彙總類**（#480 補）：分數只看主位兩支，周圍點壞了只記那一支。主位自己的擺位衝突才整類不可估；周圍某一點跟主位同代號不同座標、或同一點兩支的接收點座標不同，只記那一點的那幾支擺位不符：那一支只記原因碼，出身欄的報表代號指回原報表，舊座標本身不進輸出。**只管可估結果**：已經因別的原因拒用的周圍點不拿來判擺位衝突，可估結果的擺位只收真的用到的那幾支；整類不可估時照舊把全部輸入合併，衝突就帶空擺位（跟彙總類一樣）。
- **候選包**：把每一類的擺位疊起來，同一個喇叭代號或同一個接收點代號指到不同座標就拒收，訊息指名是哪個代號。
- **座標逐位元比，不設容差。** 同一個候選的座標都來自同一批報表的同一份輸入，不該有捨入差；差一個最小浮點刻度也拒收。
- **擺位不進排名的比較身分，排名輸出也不另外抄。** 不同候選擺位不同是本來就要比的；各類自己的擺位留在每一類的評估裡。

## 為什麼

候選代表「一種擺法」。分數拼自兩種擺法，比沒有分數還糟：看起來有答案，而且排名層只看得到數字。上一張紙把檢查對準場景之後，擺位這一格就空出來了，要有一張紙明講誰在守。不設容差是因為容差是門檻數字，門檻只准住登記簿；今天沒有任何正當理由讓同一個候選的同一支喇叭出現兩個「差不多」的座標。

## 代價

- 評估契約的形狀變更：每一類評估多一格必填的擺位，四個評估器各升一版；契約版本字串照 #408 的做法沒有升，交換格式版本怎麼跟著升記在票 #411。
- 代號是呼叫端貼的：兩支不同的喇叭貼了不同代號、其實是同一個位置，或者兩類各用一個完全不重疊的代號，這一張都不咬——它只守「同代號同座標」，不守「該用同一支的兩類真的用了同一支」。
- 批內擺位衝突的彙總類評估帶空擺位，所以它不參與候選包的跨類核對；別的原因不可估的仍帶擺位、仍參與核對。不可估的類不進代價也不進表，不影響名次。
- 不走三路接合報表的評估（手造的輸入）座標是自己給的；考卷可以這樣做，產品路徑不行——這一條沒有機器在守，靠「正式轉接器只從報表拿」與審查（跟場景指紋同一個代價）。
- 逐位元比的意思是正零與負零算不同座標；真的遇到再說，不先放寬。
- 連帶一題設計還沒定：左右兩支喇叭時，「音色平衡」那一類算的是哪一支喇叭、哪一個點的音色（跟排名層收尾題 #354 有關），另外問。
- 反射與回音這一類可估時，拒用周圍點的座標不在擺位裡，所以不參加候選包的跨類核對：別的一類若把同一個周圍點代號放在另一個座標，這一條不咬（那一支在反射這一類本來就沒被用到）。

## 拍板

2026-09-21，老闆在對話裡原話回「好」，記在票 #417 的留言。

2026-09-25，反射與回音那一條例外照老闆轉來的覆核（#480）補，覆核原話：「主位的擺位與身分先獨立確認；已拒用的周圍資料留在那筆診斷裡，不再拿來建立有效候選的擺位。不要為了容錯而丟掉原始錯誤來源。」座標本身沒有留進輸出，靠出身欄的報表代號追回原報表。
