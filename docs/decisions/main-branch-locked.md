# 主線鎖死

## 問題

主線要不要鎖，鎖到什麼程度。

## 選項

1. 不鎖，推不推靠自覺。
2. 鎖，但管理員可以繞。
3. 鎖死，誰都不能繞。

## 決定

選項 3。repo 改公開，用 GitHub rulesets：只收 PR、必要檢查全綠才能併、禁 force push、關閉管理員 bypass。改公開當第一個動作做。

## 為什麼

v2 有 796 個 commit 從未推出、528 個只在一顆硬碟、旁支領先主線 228 個沒併回、推出後改歷史害第二台電腦拉不下來。全因主線沒鎖。私有 repo 的分支保護要付費，實測回 403；公開後免費。紅燈仍能交車就不是門。

## 代價

repo 必須公開。緊急要繞過時，先寫一張決策紙解鎖，解鎖期間不得宣稱受保護。
