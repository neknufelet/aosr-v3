# 晚期混響改用無規入射吸音率、形狀因子守互易，上一代答案改為相容紀錄

## 問題

外部物理審查（票 #303、#304、#306）指出晚期混響照上一代用垂直入射吸收率 `1 − |r|²`，與型錄無規入射反推的阻抗（`catalog-absorption-random-incidence-paris-inversion.md`）
定義不一致；形狀因子逐列正規化後破壞面積加權互易 `A_i F_ij = A_j F_ji`。修任一項都會離開上一代答案，舊契約紙規定每頻帶相對差 ≤ 2·1e-4 擋合併。

## 選項

- **A：改無規入射、一起修互易**：上一代答案降為相容紀錄，改用獨立物理性質擋合併。
- **B：維持上一代定義**：三件都不動，保留舊契約。

## 決定

採選項 A。

1. 每個牆面格的吸收率用 Paris 無規入射 `α_d = 2∫₀¹ [1 − |(ζμ−1)/(ζμ+1)|²] μ dμ`，ζ 為正規化複數阻抗，以 256 點 Gauss–Legendre 數值積分；ζ 實部不大於 0 或非有限報錯。
   源項、正規化與 Eyring 修正裡用到的平均吸收率同樣換成 α_d。
2. 形狀因子：中心點近似原始值 → 交換矩陣 `G_ij = (A_i F_ij + A_j F_ji)/2` → 反覆 `G ← diag(d) G diag(d)`、`d_i = sqrt(A_i / Σ_j G_ij)`，
   直到列和最大偏差不再嚴格下降為止（沒有差值容差，也沒有迭代上限）→ `F_ij = G_ij / A_i`。
3. 報表的 Eyring T60 與 f_s 用同一個 α_d。Eyring 常數 0.161 本紙不動。
4. 上一代晚期能量答案（`blueprint/reference_art_*.json`）依 `legacy-answers-three-roles.md` 降為第二類：答案檔、比較器與命令列差距表保留，照量、照留、不擋合併。
5. 擋合併的獨立性質，相對差界線 `2^-30`，常數住在晚期混響模組：形狀因子互易與列和（多種每面格數、非立方房）；
   均勻材料房間 Eyring 修正前的能量等於用 α_d 的 Sabine 擴散場公式；穩態吸收功率總和等於源功率；同阻抗分格等於整牆；
   複數 α_d 對 4096 點數值積分真值。
6. 網格固定每面 6 格，解法照舊雙精度直接解。

## 為什麼

- Eyring 與擴散場理論本來就用無規入射吸音率；晚期混響是漫射場模型，用垂直入射會把吸收低估。
- 參考房量測（repo 外 `~/aosr-v3-work/art-trio/`、`~/aosr-v3-work/306-art/`）：改 α_d 後晚期能量 flat −4.20 dB、lowabs −3.41 dB、varied −4.04～−4.21 dB；
  T20 flat 0.105 → 0.069 s、lowabs 0.268 → 0.160 s；f_s flat 76.4 → 61.8 Hz、lowabs 121.9 → 94.2 Hz。
- 對照 30 階非同調鏡像法反射能量：晚期能量用垂直入射時高出 flat +2.64／lowabs +3.00 dB，用 α_d 時為 −1.56／−0.41 dB。
- 互易：現行最差 24.96%、中位 4.22%；修正後 2.8e-16 等級。對參考材料晚期能量影響最大 0.0068 dB（varied），均勻材料看不到；與 α_d 一起改只離開上一代答案一次。
- 五項性質實測最大相對差 4.2e-15（分格等於整牆），界線 2^-30 只擋數量級錯；256 點對 4096 點最大 1.4e-13。前例是晚期衰減 T30 性質考卷與 FEniCS 契約。

## 代價

- 報表的晚期能量、T20、T30、f_s 全部變動，跟上一代答案差到 3～4 dB、三到四成，不再能用上一代答案抓 v3 的小錯。
- α_d 是漫射場平均，格與格之間的實際入射角沒有逐對計算；分格材料差異大時仍是近似。
- Eyring 常數 0.161 與衰減換算 24·ln(10)/c 差 7.07e-4，本紙未統一（票 #306 留言）。
- 鏡像法三階與晚期混響的能量收支（票 #303）本紙未處理，改完後重量再設計。

256 點、形狀因子縮放做法、性質清單是助理依量測補定；同日老闆確認界線 2^-30（原話「Ok」）。
