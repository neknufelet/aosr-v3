# 第九段三路接合、細頻率軸與物理量報表（反射階數是設定、預設三階）

本紙取代 `stage-nine-geometric-late-split-by-order.md`（同一天）：把第 5 條寫死的三階改成**露出來的設定**（老闆 2026-09-17 拍），並依另一條平行量測線的證據改寫「代價」那一段的適用範圍——前一張紙那句「這具引擎分不出 1 dB 以內的擺法差異」講得比證據多，見下。其餘逐字沿用。前一張紙取代 `stage-nine-three-lane-stitch-and-report-random-incidence.md`，只改第 5 條的幾何能量定義、報表四欄算式與總和那一行；前一張紙取代 `stage-nine-three-lane-stitch-and-report-with-interference.md`，只改第 3 條的吸音率定義與第 9 條 T20 的角色（票 #306），更前一張再取代 `stage-nine-three-lane-stitch-and-report.md`。

## 問題

第九段要把有限元素、鏡像法與晚期混響接成一條頻率域計算路，並為一個接收點交付可追查的物理量報表。
上一代的交接自稱是臨時骨架，交接頻率、散射、反射階數、頻率軸與殘響時間又有互相矛盾的寫法；上一代報表稱為 T60 的值其實是 T20。票 #280 把矛盾逐項列出，不能只說「照上一代」就施工。

## 選項

- **A**：採票 #281 至 #287 的最新拍板，有限元素固定算到 300 Hz，重訂交接帶、細頻率軸、頻帶聚合與報表；交接另用獨立物理性質擋合併，晚期衰減擬合的 T20 訂相容契約，T30 用獨立物理性質擋合併。
- **B**：沿用上一代以 f_s（Schroeder 交接頻率）為中心、上下各半個八度的交接，以及每個八度帶只算中心頻率的報表。

## 決定

採選項 A。以下每一項都以票內最後一則相關留言為準。

1. 有限元素一律算到 300 Hz（含）。當 f_s < 300 Hz，交接下端為 `max(f_s, 150 Hz)`（兩者較大值）、上端固定 300 Hz；下端以下只剩有限元素，>300 Hz 只剩幾何路。老闆在票 #281 先回 A，之後再以留言 2 明說這套做法取代「從 f_s 往上一個八度」；票 #283 的 A／B 也由老闆自己的完整做法取代。
2. 交接段沿用上一代在對數頻率上的 C1（三次平滑且一階導數連續）平滑階梯，只更換區間；有限元素權重與幾何權重在每個頻率相加恆等於 1。老闆在票 #281 最新留言補拍這兩項，並以 DSP（數位訊號處理）的功率互補說明兩邊是能量權重。
3. f_s 先在 500 Hz 與 1000 Hz 兩帶，分別用候選房間的實際吸音率代入 Eyring（依吸音率估算殘響時間的公式）求 T60，再取兩個 T60 的算術平均代入 `f_s = 2000·sqrt(T60/V)`；V 是房間體積。票 #282 內文的 B 原指上一代全頻平均；老闆作答前，助理在對話裡把選項重排為 A＝125／250 Hz 低頻、B＝500／1000 Hz 中頻，所以老闆回 B 指中頻，票 #282 最新留言也照這個意思記錄。α=0.05 實務上供未處理牆面作基礎平均吸音率，避免空室出現無限尖峰，空室也要設定；空室用 0.05 時 f_s 一定超過 300 Hz，會走硬切換。用途來自票 #282 留言 1，硬切結果由票 #281 最新留言補拍；這個基礎值不得取代候選房間的實際吸音率來定 f_s。
   代入 Eyring 的吸音率是 Paris 無規入射吸音率（票 #306 老闆回 A，定義見 `late-energy-random-incidence-reciprocal-form-factors.md`），取代原本的垂直入射。
4. 當 f_s ≥ 300 Hz，不跑平滑交接，直接在 300 Hz 硬切換；≤300 Hz 用有限元素，>300 Hz 用幾何路，報表標出「被上限硬切」，總和照常輸出。老闆在票 #281 最新留言明說 f_s = 300 也算這一條；「300 Hz 那一點歸有限元素」是助理補定，老闆未逐字拍板。頻率軸本身不另補 300 Hz 這一點：20 Hz 起的 1/24 八度點在 300 Hz 兩側是約 293.4 Hz 與 302.0 Hz，≤300 Hz 的 94 點由有限元素算、>300 Hz 的點只給幾何路；「300 Hz 那一點歸有限元素」指 300 Hz 這個邊界值落在有限元素那一側（助理補定）。先前留言所說「這間要拉高有限元素上限」已被這則最新留言取代：老闆說高於 300 Hz 的 f_s 已經不是 f_s、模態太多而不重要。
5. 幾何路與晚期混響按**反射階數**分工：交接階數 K 以內的鏡面部分留在鏡像法，被散射掉的那一份與**K 階以上全部**交給晚期混響。逐頻的算式是
   `E_geo = |p_direct + Σ_{k=1..K} (1−s)^{k/2}·p_k|² + Σ_{k=1..K} [1 − (1−s)^k]·A_k + (E_late − Σ_{k=1..K} A_k)`。
   **K 是露出來的設定，預設 3**（老闆 2026-09-17 拍：「反射的階數要露出，可以調整，目前設定 3 為了和上一代比對」）。所以 3 這個值是**相容性的選擇，不是精度上的選擇**——決策紙不再把它寫成常數，改值不必開新紙，但改預設值要。主線目前把鏡像法列舉的階數硬上限寫成 3、四階以上直接報錯（`src/aosr/physics/room_paths.py`），那條界線要跟著放寬，怎麼放與誰守見票 #341。
   `p_k` 是第 k 階全部反射路徑壓力的複數和（同階內的干涉本來就在裡面）；`(1−s)^{k/2}` 是「每次反射壓力乘 √(1−s)」連乘 k 次——能量乘 (1−s)、壓力幅值就乘 √(1−s)。`A_k` 是晚期混響精確解按反射階數展開的第 k 階分量（源項、正規化與 Eyring 比值照 `late-energy-random-incidence-reciprocal-form-factors.md`），`E_late − Σ_{k≤K} A_k` 是 K 階以上那一段。第一項是模平方、其餘兩項非負，所以總能量恆不為負。
   報表四欄照這條定義拆：直達 `|p_direct|²`；反射 `|Σ_{k≤K} (1−s)^{k/2}·p_k|²`；干涉 `2·Re(p_direct · conj(Σ_{k≤K} (1−s)^{k/2}·p_k))`；晚期 `Σ_{k≤K} [1−(1−s)^k]·A_k + (E_late − Σ_{k≤K} A_k)`。報表要把當次用的 K 印出來。四欄相加等於 `E_geo`。
   兩端極限：**s=0** 時等於「K 階以內鏡面（含干涉）＋晚期混響的 K 階以上尾巴」，高階鏡面不再整段消失（原定義在 s=0 時晚期項歸零、四階以上沒有任何一路接手）；**s=1** 時整個反射相關部分等於 `E_late`。
   取代的是原定義 `直達 + (1−s)·(反射 + 干涉) + s·晚期`：原式只乘一次 (1−s)、不是逐次分流，而且一到三階與晚期混響的第一到第三階分配錯（權重和雖為 1、沒有重複算）。`(1−s)^{k/2}` 同時縮放直達與各階鏡面的干涉項；這一格沒有獨立依據，是本紙拍下來的（見代價）。
   s 的定義與來源不變：s 是散射係數曲線，材料沒給時預設全頻 0.1，多材料房間照上一代以反射能量加權合成一條 s 曲線（助理依票 #281 補定）；老闆在票 #285 回 A 拍保留相位疊加與帶內能量平均。逐面不同的 s 本紙不管（沒量過）。
6. 幾何路沿用 20～300 Hz 的 1/24 八度細軸，300 Hz 以上以同樣間距接續到 4000 Hz 八度帶的上緣。報表頻帶用 `[fc/√2, fc·√2)`，fc 是頻帶中心頻率，取區間內各點能量的算術平均。老闆在票 #285 回 A 拍細軸保留相位與帶內能量平均；上限、半開區間與算術平均是該票註明由助理補定、實作時寫入決策紙的細節。
   頻帶平均的鏡像法部分另取密頻率：直達、反射、干涉三項（含乘上幾何權重與 (1−s) 的部分）在帶內 `[fc/√2, fc·√2)` 每 0.5 Hz 整數倍的點上算再算術平均；
   晚期混響、s·晚期、有限元素照細軸點平均；細軸逐點值不變。老闆在票 #302 回 A；0.5 Hz 取的是票上量測用的間距，
   幾何權重與 s 在密頻率點上照同一公式求值、帶的幾何能量與貢獻怎麼由兩組點合成，是助理補定，老闆未逐字拍板。
   因此頻帶的幾何能量是「密頻率早期平均＋細軸 s·晚期平均」，幾何貢獻是逐點先乘權重再平均；頻帶的權重欄是細軸平均、只供閱讀，權重欄乘幾何能量欄不等於幾何貢獻欄，驗算總和要用兩個貢獻欄（助理補定）。
7. 每個頻帶的報表至少列有限元素、直達、反射、干涉、晚期、總和、有限元素權重、幾何權重、f_s、是否被上限硬切，以及 T20 與 T30。把有限元素、直達、反射、晚期各拆成一欄是助理補定，老闆未逐字拍板；票 #280 只定下分項與總和的報表任務。老闆在票 #281 最新留言補拍權重、f_s、硬切標記與總和照常輸出，票 #286 最新留言補拍 T20 與 T30 都報。
8. 報表的 T20 與 T30 都由同一條晚期混響衰減曲線擬合，不准自動退回；擬合無效就報錯。先在反射階數域排衰減，以 `t_k = k/f_e` 換成時間，再作加權直線擬合。T20 取 −5～−25 dB（分貝），上一代報表叫 T60 的其實就是這個，算法照上一代；T30 取 −5～−35 dB，上一代沒有。老闆在票 #286 先回 B，原話是「多做多錯，直接做出來」，最新留言再拍 T20、T30 都報。
   上一代在票 #286 內文與 `art_kernel.py` 註解記過，更早的 Perron 速率高估 12～26%，才改成這套衰減擬合；v3 不沿用上一代無效時回傳備援值的做法。
9. 三路接合因交接區間與上一代不同，依 `docs/decisions/legacy-answers-three-roles.md` 判第二類：上一代答案照量、照留但不擋合併；擋合併的獨立性質是兩邊權重和恆為 1、交接段外只剩單一路，以及硬切換連續性，也就是 300 Hz 邊界的頻率軸與總和不得缺值或重複。把硬切換連續性列為獨立性質，以及要求 300 Hz 邊界不缺不重，都是助理補定，老闆未逐字拍板。
   T20 的上一代答案在票 #306 後降為第二類，以 `docs/decisions/late-decay-t20-legacy-record-property-contract.md` 的精確常數 Eyring 性質擋合併。T30 是上一代沒有的第二類，擋合併的獨立性質是：餵入已知斜率的單一指數衰減時，T20 與 T30 都要算回同一個值；容差到實作時依量測訂，本紙不虛構。老闆在票 #251 回 A 採三類規則，票 #281、#286 與 #287 分別拍接合、擬合算法及兩種殘響時間的契約角色。
10. 主線 `src/aosr/config/fem_lane.py` 的 `FEM_FMAX_CAP_HZ = 250.0` 是照上一代搬來的設定；引擎籃（`tests/engine/`）的設定答案考卷 `tests/engine/test_shoebox_mesh.py` 拿它對上一代凍結值，本紙不改它。v3 正式路徑另立自己的 300 Hz 上限常數，名稱到實作時再定。
    `docs/decisions/precision-contract-fem-two-layers.md` 的 ≤250 Hz、29 點是既有考卷的凍結題目；`docs/decisions/fem-contract-fenics-frozen-answers.md` 的 FEniCS（外部有限元素程式）題目檔自帶網格；`docs/decisions/fem-numerical-tools-scikit-fem-p2-pydiso.md` 所記 20～250 Hz 網格量測與既有 29 點成本證據也維持有效。
    這些既有考卷與證據不因本紙失效；剛性九點考卷改用哪張網格到實作時再定，雲端時間會增加。這是票 #280 留言 2 記下的落地影響。

總和以能量域計算：`E_total = w_FEM·E_FEM + w_geo·[E_direct + E_reflection + E_interference + E_late_share]`；四項就是第 5 條報表四欄（散射留存權重已經在裡面），w 是對應權重。各欄保留線性能量，顯示時才另換成所需單位；本紙不把相對值稱為聲壓級。

## 為什麼

- 固定算到 300 Hz，讓低頻房間模態不因候選房間的 f_s 改變而少算；老闆在票 #280 留言 2 拍上限，理由是低頻難處理，先算出尖峰才能針對處理。
- 功率互補權重與段外單一路是不用上一代數字也能驗的性質；交接算法既然故意不同，就不拿上一代逐點答案把新算法鎖回去。
- 票 #280 的相位實測顯示，同一組低吸音材料的三階反射同調和在 250 Hz 是 0.045、在 4000 Hz 是 2.42；保留細軸再作帶內能量平均，可避免用單一中心頻率代表整帶。
- 有限元素解的是完整聲場，本來就含直達與反射的干涉；幾何路少了這一項，兩路算的不是同一個量。票 #302 在參考房一個接收點重算交接段 150～300 Hz：flat 逐點差的均方根從 2.52 dB 降到 0.55 dB、300 Hz 端從 +2.4 dB 變 +0.24 dB；lowabs 從 3.28 dB 降到 3.02 dB（晚期能量占大宗）。
- 高頻干涉項在一個頻帶內正負擺動比細軸間隔快，只取 24 點會偏：票 #302 實測 4000 Hz 帶補干涉項後 24 點平均多 +0.74 dB（flat）、+0.72 dB（lowabs），
  改每 0.5 Hz 一點只有 −0.04／−0.02 dB；250 Hz 帶 24 點 +0.76、密取樣 +0.52 dB，是真的干涉。晚期混響沒有相位、隨頻率平緩，照細軸。
- 算 f_s 的 Eyring T60 只負責決定交接位置；報表的 T20 與 T30 來自晚期衰減擬合，兩者刻意不是同一份數字。
- 逐階分工修掉的是**漏算**，不是重複算。原定義在 s=0 時四階以上鏡面沒有任何一路接手：對算到收斂為止的非同調鏡像法，參考房六面同材料時差 flat −0.05、lowabs −0.76、六面正規化阻抗 40 的硬房 **−4.32 dB**（硬房有 63% 的能量在四階以上）。換成逐階分工後同樣三組是 −0.02／−0.17／−0.21 dB。量測在 repo 外 `~/aosr-v3-work/303-budget/`（2026-09-15）。
- 續量（repo 外 `~/aosr-v3-work/303-nonuniform/`，2026-09-17，九個材料設定 × 三個聲源 × 四個接收點 × 交接階數 2～5，共 52 組）確認三件：換聲源位置誤差只差 ≤0.08 dB；四個接收點之間逐階分工的散布 0.01～0.66 dB，而「晚期混響給總能量、鏡像法只給起伏」那個方案散布到 5.09 dB，所以那個方案排除；交接階數從三階升到五階，六面同材料的房誤差收斂（−0.14→−0.02），吸音集中的房只從 −0.97 到 −0.73，升階不是解法。
- s=0 時的誤差拆得出來：`10log10(1 − f·(1−r))`，f 是交接階以上的能量占比、r 是晚期混響尾巴除以鏡像法真實尾巴（52 組 × 4 個交接階數，這條式子與實算差 6.1e-15 dB；它是代數恆等式，不是獨立驗證，價值在把誤差拆成兩個看得見的量）。
- **另一條平行量測線（repo 外 `~/aosr-v3-work/303-budget/`，同日）的排名證據**：40 組候選（六面各自從正規化阻抗目錄 1.6～15 抽、八個接收點平均）比排名——逐階分工 K=3 的 Spearman 0.993、前五名全中、最好那組選對；收尾階段把候選集中到最佳解附近（前五名只差 0.09 dB）仍然前五全中、最好選對，反序率 0.4%、偏差散布只有 0.012 dB。同一批裡「晚期混響給總能量」那個方案選錯最好的一組。老闆對那一條線說的是「不是要仿真，只是要有一定的鑑別力讓最佳化，精度不用到實驗室等級」，所以那把尺（排名）才是最佳化要的。
- 同一條線的非均勻材料量測與本紙的量測互相對得上：「一面側牆處理、其餘硬」那個案例兩邊各自獨立實作，逐階分工是 −0.07 與 −0.10 dB。它還多量到一個更壞、也更真實的案例（地板與天花板都處理、四面硬牆）：逐階分工 −1.90 dB。
- 升高交接階數對兩把尺的效果相反：對絕對值救不回來（吸音集中的房 K 從 3 到 5 只從 −0.97 到 −0.73 dB），對排名很有效（反序率 K=3 的 2.6% → K=5 的 1.2% → K=8 的 0.3%，散射係數 0.1 與 0.3 時 K=8 直接零反序）。**這就是要把階數露出成設定的理由**：它是「鑑別力對時間」的旋鈕，不是精度常數。
- 自寫鏡像晶格的逐面反射次數跟主線 `src/aosr/physics/room_paths.py` 的反彈牆名逐條相同（12 組位置、744 條），非均勻材料下逐階能量對主線最大相對差 6.8e-16；延伸階算到 40～120 階，最後一階新增占累計最大 7.7e-10。s=0 的參考不含晚期混響，是這一輪唯一獨立的尺。

## 代價

- f_s ≥ 300 Hz 時是硬切換，沒有平滑交接；報表必須明說，不能讓讀者誤以為仍經過平滑權重。
- 300 Hz 以上把鏡像法與晚期混響接續到細軸，計算點比六個八度帶中心多；票 #285 判斷兩路都便宜，但第九段仍要實測整體成本。
- 交接的物理校準不在本紙；老闆在票 #281 回 A，先照上一代精神接出可用路，校準另排。補上干涉項只修正兩路定義不一致，交接段對齊的擋合併考卷要拿量測訂界線、也會增加雲端時間，另題問老闆。
- 干涉項隨頻率快速正負擺動，幾何路逐點值會比原定義起伏大；頻帶平均改用 0.5 Hz 密頻率後，一份報表鏡像法多算約一萬點（實測 10000 點 3.0 秒，同時有其他工作在跑）。
- 0.5 Hz 夠不夠密只在參考房量過；更大的房間、更長的反射路徑，干涉擺動更快，要另外量。
- T20 或 T30 擬合無效就整次報錯，不會自動給一個替代數字；T20 要受已拍板的相容契約約束，T30 的獨立性質容差要等實作量完再定。
- **適用範圍（要寫進能力表）**：強吸音集中在一個大面時，四階以上鏡面改用晚期混響的尾巴會**少算**——量到最壞的一組（正規化阻抗 1.5 的天花板、其餘五面 40）在 s=0 差 **−0.97 dB**（四接收點平均），六面同材料時只有 −0.02～−0.20 dB。判準是上面那兩個量：吸音集中在大面時 r 比「同樣平均吸音率的均勻房」低 0.35（放 18 m² 側牆低 0.14、放 12 m² 側牆沒有差），而均勻房的 r 本身就隨吸音變多從 0.92 掉到 0.55，所以 r 的絕對值不能單獨拿來判。
- **精度契約不寫成一個固定的 dB**：續量前一輪那個 0.23 dB 換一種材料分布就變成 0.97 dB。要立擋合併的界線，得按 f 與 r 兩個量寫，或按房型分段；本紙不虛構數字。
- **適用範圍要按兩把尺分開講，前一張紙把它們混在一起了**：
  **絕對聲壓級這把尺**：吸音集中在大面時會少算——單一大面（天花板）最壞 −0.97 dB，而**地板與天花板都處理、四面硬牆**那種常見的房更壞，另一條量測線量到 **−1.90 dB**（八點平均，對 30 階非同調鏡像法）。要報絕對值就得把這個寫進能力表。
  **候選排名這把尺**：鑑別力夠。40 組目錄候選的 Spearman 0.993、前五名全中；連收尾階段（前五名只差 0.09 dB）都是前五全中、最好選對，反序率 0.4%。
  前一張紙寫的「這具引擎分不出 1 dB 以內的擺法差異」**講得比證據多**：那句話是從九個刻意造出來的極端設定（一面正規化阻抗 1.5 對上六面 40）推出來的，那些候選之間分布差很遠、偏差才會差 0.3～0.9 dB；真實目錄裡的候選分布相近，偏差幾乎一起動，排名保得住。本紙撤回那句。
- **升階對兩把尺效果相反**（見為什麼）：要排名更準就把 K 調高（K=8 時反序率 0.3%），要絕對值準則升階沒用，得換尾巴的算法（票 #338）。K 的成本沒量，這是票 #341 要做的。
- **s 大於 0 沒有獨立真值**：分流參考跟這條定義共用同一組逐階能量，是同義反覆不是驗證。獨立的含散射參考（另寫一支射線計算）另題。
- `(1−s)^{k/2}` 連干涉項一起縮放這一格**沒有獨立依據**，是本紙拍下來的；帶相位那一路另有一層偏移——同調參考本來就比非同調參考低 0.18～1.89 dB，把不帶相位的尾巴接上去會多算，最壞 +1.17 dB。訂容差之前要先定驗收對的是哪一把尺。
- **本紙只定義，不含實作**：主線目前仍算原定義，改法與考卷在票 #337，階數露出成設定在票 #341。
- 逐面不同的散射係數沒量；吸音面的面積與它在哪一軸也沒分開（24 m² 的面只有天花板與地板，都在同一軸）。
- 本紙只管頻率域、一個接收點；脈衝響應、時間域、圖形前端、分格材料與多接收點仍不在第九段範圍。
