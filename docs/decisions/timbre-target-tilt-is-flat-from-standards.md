# 音色平衡的目標傾斜採平坦標準原文

## 問題

音色平衡的目標傾斜要填什麼。上一代設定寫 −0.7 dB／八度，註記「Harman／house」，但票 #358 回到原始來源查，找不到這個數。兩篇 Harman 論文只拿得到摘要，摘要沒有斜率；Toole 1986／2006 全文的圖看得到下傾，文字卻沒有給數字；B&K 1974 的房內目標曲線只說低頻略升、高頻略降，200 Hz 以上約 −0.6 dB／八度是從圖估讀，不是原文。

兩份標準都以平坦為中心，給的是 ±3 dB 容許帶，不是傾斜目標。真的參考房報表量到的傾斜則是 +1.46 dB／八度，也就是往上，原因尚未驗證。

## 選項

- **A**：目標填 0 dB／八度，出處標為標準原文。
- **B**：沿用 −0.7 dB／八度，出處只能標為老闆的產品選擇。

## 決定

採 A。目標傾斜為 0 dB／八度，`source_kind = standard`，並補齊以下七格結構化出處：

| 欄位 | 值 |
|---|---|
| `source_id` | `ITU-R BS.1116-3` |
| `source_version` | `02/2015` |
| `locator` | `§8.3.4.1 Figure 2（印刷頁 15–16）；另見 EBU Tech 3276 第 2 版 §2.4 Fig. 2（p.7）` |
| `conditions` | `每支喇叭各自在參考聆聽點量 1/3 八度頻響、粉紅噪音；容許帶以平均聲壓級 Lm 為中心的平坦參考，不是傾斜目標` |
| `frequency_range_hz` | `[50.0, 16000.0]` |
| `context` | `小損傷主觀測試用的參考聆聽房（雙聲道）` |
| `verification_digest` | `sha256:8b4b442c5933b6ea030d025ea5f63c0c1799c23f8e86380fb315197b621abd9c` |

狀態仍留 `baseline`。同一條除了目標值，還裝著未經老闆拍板的 `tolerance = 0.5` 與 `worse_reference = 2.0`；狀態只有一格，現在升成 `calibrated`，會把兩個佔位值一起洗成正式數字。

有一件事要講明，免得日後誤讀這張紙：**標準原文印的是容許帶的形狀，不是一個傾斜數字**。0 dB／八度是「以平均聲壓級為中心、上下對稱」這個形狀換算過來的，原文沒有印這個數。出處種類只有四個值，沒有「標準換算」那一種，所以這一條標 `standard`，而它是換算來的這件事由同一條的 `conditions` 與這張紙寫明。

## 為什麼

三個候選裡，只有 0 dB／八度背後指得回一份查得到的原文：標準那條以平坦為中心的容許帶。這個數是從那個形狀換算來的（原文沒印它），但換算的依據一年後照樣翻得到。把 −0.7 dB／八度寫進去只能標成產品選擇，而且連它想模仿哪一條曲線都說不出來。若要改成下傾，等拿到論文全文或完成自己的聆聽驗證，再開新紙修改。

## 代價

傾斜這一分項仍不算校準過，整份排名結果會繼續標為「未校準」。要等容許帶與較差參考那一題拍完，整條才能升級。兩份標準的適用情境是評估用的參考聆聽房，不是居家；套到居家房是已知的延伸。

## 拍板

老闆 2026-09-19 在票 #368 回 A，原話就是一個字「A」。
