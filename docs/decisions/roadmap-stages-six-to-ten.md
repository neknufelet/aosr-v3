# 第六到第十段一次排好：有限元素、晚期混響、三路接合與物理量報表、分格材料；計分不接上一代

## 問題

一到四段合了、第五段收尾中。到目前每一段開工前都開一張票問「下一段做哪個」，
自己接著跑最多跑一段就停。老闆要的是把遷移做完，所以要把後面的路一次排好，之後只在該停的地方停。

## 選項

1. 維持一段一問。
2. 一次排定第六到第十段的順序與每段的邊界，之後照表做；每段內部的契約容差、要不要開新卡，仍照現行規矩問老闆。

## 決定

採選項 2，段序如下。每一段仍照 `engine-grows-by-room-workflow` 的做法：參考答案 → 契約 → v3 → 考卷 → 找碴 → 雲端綠 → 合。

- **第六段 有限元素的參考解與契約**：用凍結的上一代對參考房算低頻壓力，頻率用上一代自己的細頻軸、到它的 250 Hz 上限；
  另加一個剛性牆子案例，用長方形房的解析模態解當獨立真值，同時量上一代與 v3 離真值多遠。契約拿證據另拍。
- **第七段 有限元素的 v3**：照第六段的契約寫；求解用哪個數值庫是一張決定，開工前拍。
- **第八段 晚期混響能量**：上一代的 ART 那一路（含 Eyring 修正），參考答案 → 契約 → v3。
- **第九段 三路接合與物理量報表**：照上一代的接法——有限元素與幾何那邊用 Schroeder 頻率、半個八度平滑、能量域相加；
  鏡像法與晚期混響靠能量衰減自然交接。終點是一份報表：一個接收點每頻帶的能量（直達、反射、晚期、接完的總和）、T60、Schroeder 頻率。
  只做頻率域，不做脈衝響應。
- **第十段 分格材料與多接收點**：同一面牆不同格不同阻抗；多個接收點。
- **之後另排**：新的計分、最佳化、脈衝響應、非長方形房。

**計分不接上一代。** 上一代的分數不當參考答案、不訂契約；第九段的報表就是計分要吃的全部物理量，
新的計分是產品設計，另烤另拍。

## 為什麼

- 每段的模式已經穩定，剩下的不確定只在三處：有限元素跑不跑得動、兩條算路怎麼接、計分對什麼。查過上一代原始碼：
  參考房在 250 Hz 約八千個未知數，CPU 跑得動；接法是照房間算的 Schroeder 頻率、能量域；計分吃的是每頻帶能量與頻響。
- 先做晚期混響再接合，接合只寫一次；先寫兩路再補第三路要重做。
- 上一代的計分反覆改過、老闆自己說亂；把亂的鎖進契約再拆，比從物理量重打貴。

## 代價

- 段序是現在排的，第六段做完若發現有限元素的形狀跟預期不同，要回來改這張紙，不准默默換順序。
- 第九段的報表只有頻率域，聽感那一路（脈衝響應）沒有位子，要的話另排。
- 有限元素的細頻軸會讓參考答案檔變大、上一代多跑幾分鐘。
