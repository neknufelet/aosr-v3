# 音色傾斜的目標、容許帶與較差參考

## 問題

2026-09-19 與 2026-09-20，老闆用兩張紙依序拍了音色平衡傾斜的三個數字：先定目標，再定容許帶與較差參考，並把整條從測試基線升為正式數字。兩張共同定義同一個設定 `timbre_balance.target_tilt_db_per_octave`（音色平衡每八度目標傾斜）。2026-09-21 決策紙份數滿了（票 #412），所以把兩張目前有效的數字、來源欄與狀態合在這裡；後一張改掉前一張的出處種類與狀態也明寫，不讓舊值並存。

## 選項

- 目標值當時在 A「0 dB／八度，依標準以平坦為中心的容許帶換算」與 B「沿用 −0.7 dB／八度，但只能標成老闆的產品選擇」之間選。
- 容許帶與較差參考當時在 A「1.0 與 2.0 dB／八度」與 B「維持 0.5 與 2.0 dB／八度」之間選。另有較寬但未採的讀法：只拿 250 Hz–2 kHz 的 3 個八度換算，容許帶會是 2.0 dB／八度。

逐張的完整選項在封存區的舊紙；第一張只選目標，第二張才選另外兩個數字與整條狀態，沒有一個當時存在的三數共同選項。

## 決定

**目標傾斜採平坦形狀換算的 0 dB／八度（2026-09-19）**

採 A，目標值為 0 dB／八度。標準原文提供的是以平均聲壓級為中心、上下對稱的平坦容許帶，不是印出「0 dB／八度」這個數；0 是由形狀換算而來。當時先把出處種類設定 `source_kind = standard`（標準）並讓狀態留在 `baseline`（測試基線），因容許帶 0.5 與較差參考 2.0 尚未拍板；2026-09-20 的下一小節把整條出處種類改成產品選擇，並升為正式數字，現在以後一個狀態為準。

目標值保留七格結構化出處：

| 設定欄 | 值 |
|---|---|
| `source_id`（來源識別） | `ITU-R BS.1116-3`（國際電信聯盟無線電部門標準） |
| `source_version`（來源版本） | `02/2015` |
| `locator`（原文位置） | `§8.3.4.1 Figure 2`（圖 2，印刷頁 15–16）；另見 `EBU Tech 3276`（歐洲廣播聯盟技術文件）第 2 版 §2.4 Fig. 2（圖 2，p.7） |
| `conditions`（量測條件） | 每支喇叭各自在參考聆聽點量 1/3 八度頻率響應與粉紅噪音；容許帶以平均聲壓級 Lm 為中心的平坦參考，不是傾斜目標 |
| `frequency_range_hz`（頻率範圍） | `[50.0, 16000.0]` |
| `context`（適用情境） | 小損傷主觀測試用的雙聲道參考聆聽房 |
| `verification_digest`（查證摘要） | `sha256:8b4b442c5933b6ea030d025ea5f63c0c1799c23f8e86380fb315197b621abd9c`（SHA-256 雜湊） |

**容許帶採 1.0、較差參考採 2.0，並改成正式數字（2026-09-20）**

採 A。設定 `timbre_balance.target_tilt_db_per_octave`（音色平衡每八度目標傾斜）的目標值為 0、容許帶為 1.0 dB／八度、較差參考為 2.0 dB／八度，寫在 `src/aosr/config/data/quality_targets.toml`。代價公式是 `max(0, |量到的傾斜| − 容許帶) ÷ 較差參考`；容許帶內代價為零，傾斜到 3.0 dB／八度時代價為 1。

容許帶 1.0 是把標準的 ±3 dB（分貝）頻率響應容許帶換算到 80–4000 Hz 的傾斜擬合段：跨 5.64 個八度，理想傾斜線在兩端各偏半個跨距，換算上限為 1.06 dB／八度，再取保守整數 1.0。較差參考 2.0 沒有原文可引，是產品選擇。

三個數字都拍完後，整條狀態由 `baseline`（測試基線）升為 `calibrated`（正式數字）。後一張紙也修改前一張紙的出處種類：整條設定 `source_kind = product_choice`（產品選擇），不再是 `standard`（標準），因登記簿一條只有一格出處種類；若仍標標準，較差參考 2.0 會搭便車冒充有依據。出處字串必須逐項說明：目標值 0 與容許帶 1.0 由 `ITU-R BS.1116-3`（國際電信聯盟無線電部門標準）`02/2015 §8.3.4.1 Figure 2`（圖 2）的平坦容許帶換算，較差參考 2.0 是產品選擇。

## 為什麼

- 上一代的 −0.7 dB／八度註記指向 Harman（哈曼）與 house curve（房內目標曲線），但票 #358 查不到這個數。兩篇 Harman（哈曼）論文只有摘要，摘要沒有斜率；Toole（托爾）1986／2006 全文的圖有下傾、文字沒有數字；B&K（聲學量測公司）1974 的房內目標曲線只說低頻略升、高頻略降，200 Hz 以上約 −0.6 dB／八度只是看圖估讀。兩份標準以平坦為中心並給 ±3 dB 容許帶，所以 0 是唯一能回到可查原文形狀的目標。
- 取 1.0 而不是 1.06，是因換算用理想直線，而真實容許帶在兩端還會放寬；保留一位小數會製造假精度，取 1.0 又比換算上限稍嚴。
- 真實參考房量到 +1.46 dB／八度，在這組數字下代價是 0.23，只算小瑕疵；代價 1 落在 3.0 dB／八度，等於擬合段兩端約差 17 dB。若維持容許帶 0.5，同一間房會得到 0.48，接近中等瑕疵。
- 那間參考房不是符合標準的證據：+1.46 是往上傾、原因未驗，並有一個 75 Hz、−12.8 dB 的深谷，連當時佔位的峰谷界線都過不了。它只用來檢查尺在真實量級能否分出好壞，不用來主張房間品質。

## 代價

- 平坦目標與 1.0 容許帶都是由標準形狀換算，不是原文直接印出的傾斜數字；標準適用於評估用參考聆聽房，不是居家，把它延伸到居家是已知限制。日後若取得完整感知文獻或完成聆聽驗證，必須用新紙修改。
- 只拿標準畫出 ±3 dB 的 250 Hz–2 kHz 區段重算，會得到較寬的 2.0 dB／八度。較差參考 2.0 本身也沒有文獻依據，決定的是多糟算滿額代價；兩者日後都可由聆聽驗證重訂。
- 整條標產品選擇後，只看出處種類會看不出目標值與容許帶其實有標準形狀可引，必須讀出處字串；要讓三格各有自己的出處種類，就得改登記簿結構，另開一題。
- 合併帶來的代價：目標、容許帶與較差參考在機器眼裡變成同一題；以後其中一個數字或出處角色要翻案，都必須取代整張，並重述另外兩個仍有效的數字。
