# 音色的積分量每八度等權，不讓取樣密度變成票數

## 問題

參考房的 flat（水平）材料只把 300 Hz 以下從正式 1/24 八度軸的 94 點加密到 1121 點，
300 Hz 以上一點都沒動，音色評估器的傾斜卻從 1.052 變成 2.057 dB/oct（每八度分貝），
起伏 RMS（均方根）從 4.77 變成 3.92 dB（分貝）；連資料完全相同的 6450 Hz 與 6834 Hz
兩個谷，深度也從 −14／−16 變成 −20／−22 dB。原因是四處都把每個取樣點當一票：
傾斜的直線擬合、能量域平滑、起伏均方根，以及對目標偏差的扣平均與均方根。

## 選項

1. **A：每點等權。** 維持現狀；哪一段取樣密，哪一段就有更多票。
2. **B：每 Hz（赫茲）等權。** 線性頻率跨度相同就同票，高頻的一八度會比低頻的一八度重很多。
3. **C：每八度等權。** 每點的票數等於它代表的 log2(f)（以二為底的頻率對數）寬度；
   50→100 Hz 與 1000→2000 Hz 都是一八度，基本權重相同。

## 決定

採 C，四處用同一份整軸八度權重：傾斜用加權最小平方，能量域平滑在每個截短視窗內做
加權平均，起伏用加權均方根，對目標偏差的扣平均與均方根也加權。計分範圍只從整條軸
取權重子集，不在範圍邊界重算，免得邊界改變範圍內點原本代表的寬度。

raw（原始）峰谷照 #432 保留：`_features`（峰谷找法）、半深度寬度與窄於軸解析度標記仍看
原始曲線逐點，不為擬合降回粗軸，也不重取樣。加密若真的找到粗軸沒抓到的窄峰，峰谷清單
與起伏均方根本來就應該變。

**同一原則延伸到聲道匹配的寬頻音量差（#450，聲道匹配評估器 v5）**：左右聲道各自的寬頻能量改成
每點乘它在寬頻範圍（登記簿 `channel_matching.broadband_range_hz`）內代表的八度寬度再加總，
兩者相比取 dB。格子只由範圍內的點組成：內點以鄰居中點為界，兩端各往外延半個鄰距、再切到
範圍邊界——不像音色那樣直接伸到邊界，因為這一類不要求資料蓋滿範圍，資料只到 100–200 Hz 時
伸到 20 與 8000 Hz 會把兩端點的權重放大好幾倍。範圍外的點不組格子，不改變範圍內的尺。
正式 1/24 等比軸上每格等寬，所以只差在範圍兩端的半格；低頻加密（例如 #435 驗證軸的每 1 Hz）
不再讓低頻在寬頻音量裡多拿票。

**再延伸到聽音區比較各點的整體音量（#455，聽音區評估器 v4）**：這一格原本由呼叫端算好傳進來
（`broadband_mean_total_energy_db`），產品程式裡沒有人算，唯一在算的考卷用每點平均。改成評估器
收每個接收點的原始曲線（頻率與總能量），自己用跟聲道匹配同一支權重算範圍內每八度等權的平均能量；
範圍由呼叫端傳入、算進設定指紋。要比的各點在範圍內必須是同一條軸，不同就整類不可估（頻率軸不一致），
範圍內沒資料也不可估，不硬比。不同候選分別用搜尋軸與驗證軸算的結果能不能同表，原本留給 #435 兩階段計算一起定；2026-09-25 其中「不能默默混比」這一部分提前拆出（#489，見下一段）。

**音色與聆聽區的實際頻率支撐進比較身分（#489）**：音色的評估支撐每一支聲道列出實際讀到的完整頻率串（輸入軸落在覆蓋範圍內的每一點，就是對目標偏差曲線的那一串；覆蓋範圍外的點不改任何分數，最多差浮點捨入那一級）；聆聽區的評估支撐列出整體音量用的那一串，加上每一個該量接收點（主位與周圍點）上游音色的那一串，聆聽區評估器升一版。支撐不同就分表。不改量法、代價、門檻或峰谷診斷；列的是實際頻率，不是軸的名稱、也不是只記主位或頭尾點數。粗細結果什麼時候可以同表，另以明確的收斂／誤差規則放寬，這一刀不預先放行。

## 為什麼

老闆的判準是：「增加取樣密度是增加解析度，不是增加那一段的權重」。聲學頻率用比例看，
兩段各一八度的區間基本權重相同；加密只把同一段切成更多小份，不會憑空增加那一段的票數。

## 代價

## 拍板

2026-09-23，老闆在票 #446 原話：「#446 做，先於 #435。明定為『每八度等權』，不是每 Hz
等權；一併修傾斜擬合、能量域平滑、起伏 RMS，以及對目標偏差的扣平均與 RMS。raw 峰谷
保留，不為擬合而降回粗軸。」「考卷要防『多取點就多加權』，但不能禁止『加密發現新缺陷後
答案合理改變』。」白話：「原本是低頻班 94 個學生、高頻班幾十個學生一起投票；現在低頻班
突然變成 1121 個學生，高頻班沒變，那最後投票結果當然被低頻班淹沒。問題不是低頻資訊變
詳細，而是詳細資料被錯當成更多票。」「增加取樣密度是增加解析度，不是增加那一段的權重。」

2026-09-25，老闆在 #489 原話：「A，現在補。#489只補音色與聆聽區的實際頻率支撐及比較資格；不同支撐先分表，不改既有量法、代價、門檻或峰谷診斷。同時更新兩張決策紙，把這一部分從 #435 提前拆出；驗證選人、收斂與重排仍照原時程。完整支撐要沿上游音色傳到聆聽區，不只記主位、頭尾點數或軸名稱。保留同軸同表、分數不變的控制組，以及只帶音色也能阻擋混軸的反例。將來要讓粗細結果同表，另以明確的收斂／誤差規則放寬，不在這一刀預先放行。先把「不能默默混比」守住，不等於現在就要解完「什麼時候可以混比」。」
