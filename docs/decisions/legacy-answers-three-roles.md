# 上一代答案在新引擎考卷裡分成三種角色

## 問題

`docs/decisions/engine-grows-by-room-workflow.md` 要求每段先凍結上一代參考答案、訂精度契約，再寫新引擎；它也說上一代是相容性參考，不自動等於物理真值。
當新引擎故意更換算法、網格、元素或精度，現有做法沒有明說上一代答案是否仍擋合併，也沒有要求降級前先由別的真值接手，可能留下無人把關的空窗。
本紙補強該做法，不取代也不修改原紙。

## 選項

- **A**：補上三種角色、獨立真值的最低條件、開工時判類與改類流程，以及舊契約只准由新紙取代的規則。
- **B**：不立通則，每遇到一張契約再個別處理。

## 決定

採選項 A，補強 `docs/decisions/engine-grows-by-room-workflow.md`，不取代它。

- **第一類：算法相同，只換寫法或精度。** 例如鏡像法的幾何、振幅與總量；上一代答案仍是擋合併的相容契約。
- **第二類：同一個物理，故意換算法。** 算法、網格、元素或精度任一項不同，例如有限元素改用 gmsh（產生網格的工具）與 P2（二次元素）；上一代答案降為相容紀錄，仍要量、仍要入庫、差距仍寫進證據，但不擋合併。
- **第三類：上一代沒有或不接。** 例如材料最佳化與評分；不參考上一代答案。
- 第二、三類用來擋合併的一定要是獨立真值：解析解、物理性質、自我收斂或外部程式至少一種。沒有獨立真值，就不准把上一代契約降級。
- 每一段開工時，必須在票上寫明屬於哪一類與理由；要改類別，另走 `decision`（決策）票。
- 舊契約一律開新紙取代，不修改原紙。

## 為什麼

- 第一類保留相容契約，能守住只換寫法或精度時不該變的行為。
- 第二類若仍要求逐點貼住上一代，會把已決定更換的舊算法、舊網格或舊元素鎖回來；改成相容紀錄，差異仍可追查，又不拿舊算法阻擋新算法。
- 第二、三類若沒有獨立真值接手，就可能讓新做法與上一代的約束一起消失；因此沒有獨立真值時，不准降級。
- 開工時先在票上判類，讓契約與考卷在實作前就有依據；類別改變與舊契約取代都留下新的拍板紀錄，不回頭改寫歷史。
